# HG: файлы и время хоста

HG.PGM подключает FAT12-диск папки хоста через FT2232 и синхронизирует
время UniDOS. Работает на MC6800 и HD6303. При SD A/B/C свободной буквой
обычно становится D; использовать букву из сообщения драйвера.
HGTIME.PGM обновляет только время, не подключает новый диск.

```text
B:HG
D:DIR
D:HVIEW D:LENA.IFF
```

Сервер — C11/libftdi1, папка меняется без перезапуска демона. Поддержаны
вложенные DOS 8.3 каталоги, чтение/запись/создание/удаление. Локальные
изменения хоста и гостя объединяются с журналом; конфликты сохраняются
отдельно. Не удалять служебные img/base/state/export файлы при незавершённых
записях. Пределы/восстановление/сборка описаны в
[host/hg/README.md](../host/hg/README.md).

MMIO E670..E673 содержит два FIFO по 64 байта; CPU переносит байты
между FIFO и RAM, HG не читает SRAM автономно. v2 даёт пакеты до 32 байт
при TCK<=1 МГц; v1 сохранён. Все биты control/status и правила request,
SELECT, credit/final TX/flush — [REGISTERS.md](REGISTERS.md#hg-e670e673).

HG занимает интерфейс FTDI на время работы. Сборка/запись FPGA проводится
штатным JTAG-комплектом с освобождением транспорта, затем сервер запускается
снова. Обычная добавка файла в папку не требует перепрошивки FPGA/ROM.
