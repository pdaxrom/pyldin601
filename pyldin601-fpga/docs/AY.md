# AY-3-8910

Для приложения использовать очередь и эффекты GAMEBIOS INT E6;
[практическое руководство](PROGRAMMING.md#ay-ноты-кадры-частота-и-таймер)
содержит порядок CLOCK/RATE/FRAME/PLAY, длительность NOTE, паузу,
пополнение очереди и полный пример UniAS. Ниже описан аппаратный уровень.

Три канала AY и штатный beeper смешиваются в один сигнал, подаваемый на
оба аудиовыхода платы: FPGA 21/22. Цифровые генераторы и кривая громкости
сверены с используемым в БК AY. После Reset master AY=2 МГц, основной шаг master/8
=250 кГц; частота программируется через E69B–E69F; выбор CPU 1/2/4/8 МГц не меняет высоту тона.

| Регистры E610–E61F | Значение |
|---|---|
| R0/1, R2/3, R4/5 | Периоды A/B/C, 12 бит, младший байт первым |
| R6 | Период шума, 5 бит |
| R7 | Bits 0..2 выключают tone A/B/C; 3..5 выключают noise A/B/C |
| R8..10 | Громкость 0..15; bit 4 выбирает envelope |
| R11/12 | Envelope period, 16 бит, младший байт первым |
| R13 | Shape, 4 бита; любая запись повторно запускает envelope |
| R14/15 | Latch GPIO; неподключённые входы читаются как FFh |

Частота tone=master/(16×period). Период 0 трактуется как 1. Шум использует
17-битный LFSR и дополнительный делитель 2. Envelope поддерживает все
16 shapes, hold/alternate/attack, повторный запуск и 16-битный период.
Ненулевой envelope period имеет делитель 16, нулевой — вдвое меньший шаг.
Неиспользуемые биты регистров маскируются.

Одна EBR 1024×9 содержит регистры, счётчики, логарифмическую таблицу
громкости и микропрограмму. Один девятибитный ALU обслуживает все пять
генераторов на 96 МГц: 43 операции по пять тактов внутри фиксированных
384 fast-тактов минимум звукового шага (2 МГц); более низкая
частота AY увеличивает интервал. Запись CPU обслуживается не позднее пяти
fast-тактов; минимальное расстояние записей CPU при 8 МГц — 12 тактов.
Основная SRAM и видеоарбитр для звука не используются.

Три уровня до 127 суммируются с beeper до 128 (максимум 509). Sigma-delta
на 24 МГц формирует выход. Reset выключает AY и очищает регистры и
счётчики. Старые beep-программы используют прежний аппаратный бит.

`B:AY` или `E:AY` через HG — нативное HD6303-демо. Оно отправляет 14-байтовые
кадры через [INT E0](FPGA-BIOS.md), проигрывает мелодию на трёх каналах
и использует системные 50 Гц для темпа. ESC выключает AY и возвращает
UniDOS. UniAS: 350 байт кода/данных, 29 relocation, PGM 424 байта.

`YPLAY.PGM` воспроизводит стандартные YM/PSG и распаковывает LHA/LH5
на HD6303 в расширенную SRAM. Музыка идёт через отдельный IRQ INT E4 с частотой записи; SD/HG
во время воспроизведения не используется. [Команды и форматы](MUSIC.md).

## Программируемый тактовый шаг и музыкальный IRQ

E690–E69F не пересекаются с ACIA 601А по E645–E647. CPU 1/2/4/8 МГц,
PAL 50 Гц и звуковой master работают независимо; новые clock/PLL не нужны.

| Адрес | Чтение / запись |
|---|---|
| E690 | Статус: 7 pending, 6 overrun, 5 divider busy, 4 bad config, 0 enable. Запись: 0 enable, 1 ACK, 2 restart, 3 clear bad config |
| E691 | Идентификатор 59h (`Y`) |
| E692–E695 | BE32 период таймера в тактах 24 МГц; запись в shadow |
| E696 | Запись bit 0 применяет период, обнуляет счётчик и pending/overrun; 0 отклоняется |
| E697–E69A | BE32 снимок счётчика: сначала читать E697, затем остальные байты |
| E69B–E69E | BE32 Q16 делитель: чтение committed, запись shadow |
| E69F | Запись bit 0 применяет делитель; чтение bit 0 busy до ACK от AY |

Частота master = **768000000 × 65536 / divider**. Интервал основного
шага AY = divider/65536 тактов 96 МГц. Дробный накопитель чередует целую
длину и длину +1; новая настройка применяется на границе звукового шага.
При busy следующая команда отвергается. Допустимо 01800000h–FFFEFFFFh
(частота не выше 2 МГц), иначе устанавливается bad config.

| Master | Q16 divisor | Реальная средняя частота, Гц |
|---|---|---:|
| 2 МГц | 01800000h | 2000000 |
| 1 МГц | 03000000h | 1000000 |
| Spectrum | 01B11101h | 1773400.019 |
| MSX | 01AD1ACDh | 1789773.025 |

Таймер считает до period−1, устанавливает pending и начинает новый период.
IRQ остаётся активным до ACK; если новое событие приходит при pending,
ставится overrun. ACK одновременно с compare сохраняет **новое** событие.
Stop/restart или commit периода отменяют прежнее pending. 50/60/100 Гц
соответствуют 480000/400000/240000; 1 Гц — 24000000. Reset: таймер выключен,
период 480000, делитель 01800000h, флаги очищены.

Оба BIOS направляют музыкальный IRQ в INT E4 (EFC8/EFC9, page high nibble
EDF2). Приоритет: аудио, затем PAL, затем клавиатура; источники имеют
отдельные подтверждения. При совпадении PAL с клавиатурой тик обслуживается
перед soundkey, чтобы чтение PIACRB из beeper не теряло системный тик.
При нулевом векторе
музыкальный IRQ подтверждается без вызова. BIOS восстанавливает E6F0/E6F1,
сохраняя исходное расположение кадра; группа кодируется адресом возврата
обработчика. [Сохранение селекторов](MEMORY.md#irqnmiswi-и-y-код).
