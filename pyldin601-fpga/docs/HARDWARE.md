# Характеристики и аппаратная архитектура

FPGA-Пълдин 601/601А использует плату Z-pdaXrom-TV / hardware-lcd,
Lattice LCMXO2-7000HC-4TG144I и внешнюю 16-битную SRAM 2 МиБ с byte enables.
Процессор обращается к ней байтами; видеокэш также читает пары байтов.
Кварц 12 МГц и одна PLL дают 24 МГц system/PAL и 96 МГц SRAM/AY fast.
Принятые обращения памяти завершаются перед Reset и сменой частоты.

| Возможность | Реализация |
|---|---|
| CPU | MC6800 или расширенный HD6303R instruction set |
| Runtime speed | 1/2/4/8 МГц, смена коротким нажатием Reset |
| Bootstrap | HD6303 ISA, 4 МГц, EBR BIOS 8 КиБ |
| Память | Базовая RAM 64 КиБ, банковая RAM 888 КиБ, GPU SRAM 1 МиБ; ROM/font в оставшейся SRAM |
| ROM | 64 КиБ страниц + BIOS 4 КиБ + font 2 КиБ с SD |
| Видео | Composite PAL 625/50, 6-битный DAC |
| Новая графика | 320×200, indexed 256 цветов, HAM8, HAM8+RGB222 overlay |
| Blitter | FILL/COPY/keyed COPY/byte read-write/VBL FLIP |
| Звук | AY-3-8910, три tone-канала, noise/envelope, native beeper |
| Ввод | PS/2 клавиатура и мышь, программные команды мыши, загружаемый указатель |
| Накопитель | SD SPI, прямой LBA, MBR/extended EBR, FAT12 UniDOS |
| Host link | FT2232 HG, RX/TX FIFO, пакетный протокол v2 |
| UART | FT2232 канал B, 150..115200, 7/8 бит, parity/stop, FIFO |

Данные музыкальной записи и GPU-страницы не пересекаются.
Полная карта — [MEMORY.md](MEMORY.md); все новые регистры —
[REGISTERS.md](REGISTERS.md); последовательность запуска — [BOOT.md](BOOT.md).

## Модели и классическое видео

Модель задаётся BIOS Setup и определяет P601.ROM/P601A.ROM, native BIOS
и способ чтения видеопамяти. ISA выбирается независимо: возможны все
четыре сочетания 601/601А и MC6800/HD6303. Это не реализация внутренних
портов/SCI физического HD6303; область применения описана в [CPU.md](CPU.md).

| Native режим | 601 | 601А |
|---|---|---|
| Текст | 40×25 моно | 80×25 моно; 40×25 моно или цвет |
| 16 IRGB | 80×200 | 160×200 |
| 4 цвета | 160×200, четыре палитры | 320×200, четыре палитры |
| Моно графика | 320×200 | 640×200 |

Шрифт 8×8. В цветном 40-колоночном тексте 601А перед символом хранится
атрибут: blink bit7, FG bits6:4 (8 цветов), BG bits3:0 (16 цветов).
INT12 native BIOS: A=0 text40, B=0 mono/B!=0 colour; A=1/2/3 графика;
A=4 text80 на 601А. Номера относятся к текущему BIOS_A, а не переставленным
номерам отдельных старых руководств. Первичная консоль обеих моделей
отдельная: 40×24, до перехода к native BIOS.

Расширенное видео одинаково для 601/601А и масштабирует framebuffer
320×200 в PAL-окно **48 мкс × 264 строки поля**. Logical native 320/640
и число строк CRTC сохраняются; повтор физической строки не запускает
повторный SRAM DMA. Частота PAL и системного тика — 50 Гц.
Штатные MC6845-порты являются интерфейсом совместимости, не отдельным
полным произвольным генератором новых видеотаймингов.

Indexed палитра принимает RGB888 через программную генерацию PAL-таблицы.
HAM8 хранит 262144 RGB-состояния и зависимости между соседними пикселями;
overlay v6 декодирует весь исходный фон и накладывает RGB222 передний план.
Число RGB-состояний не означает физический 18-битный DAC. Composite PAL
ограничивает горизонтальную чёткость и различимость оттенков.
[Графика](GRAPHICS.md), [HAM8](HAM.md), [изображения](IMAGES.md).

## Арбитраж и прерывания

SRAM обслуживается одним контроллером на 96 МГц, слот 6 тактов=62,5 нс.
CPU имеет фиксированные слоты без HOLD; bootstrap/video/GPU используют
остальные. Внутри GPU строковый fetch имеет приоритет над blitter.
Обычные режимы читают 160 слов на строку; layer v6 — 160 слов foreground
и 160 background, сохраняя RGB666 пары в двух EBR.
Рисование остаётся зависимым от количества команд/скорости CPU:
VBL=50 Гц не обещает 50 игровых кадров/с в любой сцене.

CPU IRQ объединяет PAL pending, native keyboard, raw PS/2 и music.
Raw обслуживает ROM переводчик, audio/PAL/keyboard имеют отдельные ACK;
музыкальный источник направляется в INT E4, PAL сохраняет штатный INT05.
BIOS обеих моделей сохраняет bank/group при IRQ/NMI/SWI. Raw capture
выключает только клавиатурный путь, не музыку/системные часы.
Описание источников/ACK — [REGISTERS.md](REGISTERS.md),
программного перевода — [KEYBOARD.md](KEYBOARD.md).

## Выходы и конфигурация платы

Оба audio-выхода несут одинаковую mono-сумму AY+beeper. Для динамика нужен
внешний усилитель/активные колонки; direct stereo-разделения AY нет.
RGB LED показывает Caps Lock (красный) и Кир/Лат (зелёный); синий выключен.
Частота показывается 01/02/04/08, bootstrap=04.

На плате hardware-lcd уже разведены клавиатурная и мышиная пары PS/2,
а также UART второго канала FT2232D. Соединения сверены непосредственно
по Eagle `hardware-lcd/main.sch` проекта Z-pdaXrom-TV и mapping символов
на физические площадки U1:

| Интерфейс | Сеть | U1 pin | Подключение |
|---|---|---:|---|
| PS/2 клавиатура | PS2_CLOCK / PS2_DATA | 2 / 138 | Mini-DIN контакты 5 / 1 |
| PS/2 мышь | MS2_CLOCK / MS2_DATA | 4 / 5 | Mini-DIN контакты 6 / 2 |
| UART, передача FPGA | USBUART_RX | 132 | FT2232D BDBUS1/RXD, pad 39 |
| UART, приём FPGA | USBAURT_TX | 133 | FT2232D BDBUS0/TXD, pad 40 |

`USBAURT_TX` — исходное имя сети с опечаткой; RX/TX в именах схемы
относятся к FTDI. Питание PS/2 на контакте 4 — +3V3, контакт 3 — GND.
Мышиная пара выведена на дополнительные контакты общего разъёма:
разветвитель должен отдельно соединять контакты 6/2 с CLOCK/DATA мыши.
Для передачи команд PS/2 требуется открытый сток, выдающий только 0/Z.

Клавиатурная и мышиная пары подключены независимо. Мышиный порт имеет
приёмный FIFO и управление открытым стоком: команды, ACK, инициализацию
и разбор пакетов выполняет программа. Загружаемый указатель 16×16 накладывается
на графику после декодирования цвета, включая HAM8; в тексте используется
существующий курсор CRTC. UART имеет независимые TX/RX, FIFO и программный
выбор скорости 150..115200. FTDI channel A занят HG/JTAG, channel B — UART;
CPU не имеет отдельного DMA от HG. [Регистры и драйверы](INPUT.md).
Pin constraints находятся в `pyldin601_classic.lpf`,
top-level — `rtl/pyldin601_classic.vhd`.

Сборка с DMA, мышью, указателем и UART: 6674/6864 LUT,
3359/3432 slices, 3044/6864 PFU registers, 24/26 EBR, 1/2 PLL.
Запас — 190 LUT, 2 EBR и одна PLL. SRAM-10 ограничения и SRAM→CPU бюджет
27 нс сохранены; TRACE проходит 96 МГц без нарушений setup/hold;
сборка/воспроизводимые проверки — [BUILD.md](BUILD.md).
