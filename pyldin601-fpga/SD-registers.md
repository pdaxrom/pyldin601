# SD и служебные регистры

Все устройства находятся в классическом окне **E600–E6FF**. SPI имеет базу **E660**.
Аппаратный FDC и электронный диск удалены. E680–E683 читаются как нули;
записи игнорируются. Дисковые обращения выполняет INT E2 из ROM через SPI.
Порядок регистров повторяет SPI нового Пълдина из HD6303-эмулятора.

Графическое расширение RGB332 занимает свободное окно **E650–E65F**;
команды, страницы и формат пикселей описаны в [GRAPHICS.md](audit/GRAPHICS.md).

| Адрес | Семантика |
|---|---|
| E660 | DATA_H: старший байт 16-битного обмена |
| E661 | DATA_L: запись запускает обмен, чтение возвращает младший байт |
| E662 | READY бит 7; конфигурация: SS0 бит 0, SD CS бит 1 (0 активен), 16-битный обмен бит 4, SSM бит 5; reset 23h |
| E663 | Делитель: частота SCK = системная частота / (2 × (значение + 1)) |
| E664 | POUT |

Загрузку SD, разбор MBR/FAT16, чтение файлов и сохранение настроек выполняет
CPU в HD6303 режиме до lock. Аппаратных
файловых портов нет. Один SPI shifter обслуживает CPU до и после lock.
Рабочий INT E2 из страницы B ПЗУ пользуется этими же регистрами и сохраняет
состояние инициализированной карты. Программа обязана отпускать CS и ждать READY.

DMA между SD и основной SRAM нет. INT E2 переносит сектор напрямую между
SPI и буфером пользователя в RAM, проверяя CRC16. Для MBR/BPB служба разделов владеет отдельным буфером в heap UniDOS. Арбитр SRAM обслуживает CPU, видео, boot-порт и графическое
расширение; графика использует свободные слоты без HOLD.

E6A2 доступен для чтения после lock: bit 0 — SDHC/block addressing. Остальные биты равны нулю.
[Дисковый ABI и графические/звуковые входы INT E0](audit/FPGA-BIOS.md).

AY занимает E610–E61F: прямые байтовые регистры R0–R15.
[Генераторы и смешивание звука](audit/AY.md).

HG использует отдельные GPIO FTDI/JTAG и два 64-байтовых EBR FIFO.
Передачу данных между HG и RAM выполняет CPU; SRAM-запросов от HG нет.

| Адрес | Семантика HG |
|---|---|
| E670 | DATA: чтение извлекает байт RX, запись добавляет байт TX |
| E671 | STATUS: bit 0 RX ready, bit 1 TX room, bit 2 SELECT, bit 3 TX empty, bit 6 RX overflow, bit 7 TX underflow |
| E672 | CONTROL: bit 0 request/TDO enable, bit 1 RX enable, bit 2 TX enable; bit 7 очищает FIFO/ошибки, только при request=0 и SELECT=0 |
| E673 | ID = 48h (`H`) |

Request при SELECT=0 поднимает TDO, хост поднимает SELECT и читает заголовок.
Перед сменой направления CPU ждёт TX empty; RX отключён при отправке и
TX отключён при получении. Reset очищает интерфейс и освобождает TDO.
[Драйвер, формат пакетов и подключения](audit/HG.md).

Служебное окно доступно только до lock; чтение статуса E6A0 доступно и после lock:

| Адрес | Семантика |
|---|---|
| E6A0 | Запись 00h–0Fh до E6A3: bit 0 выбирает 601/601A, bit 1 рабочую MC6800/HD6303 ISA, bits 3–2 начальную частоту 1/2/4/8 МГц; A5h: проверка конфигурации/CRC/модели и lock; чтение: locked бит 7, error бит 6, код начальной частоты bits 3–2, выбранная ISA bit 1, model_a bit 0 |
| E6A1 | Текущий этап 01–0C; EE при ошибке загрузчика; тот же этап виден на текстовом экране |
| E6A2 | Режим карты: запись бит 6 SDHC, чтение бит 0 SDHC |
| E6A3 | Последовательная запись 64 байта заголовка выбранного ROM версии 2 |
| E6A4–E6A6 | Физический байтовый адрес SRAM, младший байт первым |
| E6A7 | Запись байта по физическому адресу с автоинкрементом |
| E6A8 | Busy бит 0, error бит 7; ждать освобождения перед следующим запросом памяти |
| E6A9 | Добавить байт к CRC32 |
| E6AA | Сбросить аккумулятор CRC32 |
| E6AB | Запись любого байта запускает чтение SRAM с автоинкрементом; после снятия Busy чтение возвращает полученный байт. Само чтение регистра нового запроса не запускает |
| E6AC–E6AF | До lock: завершённый CRC32, младший байт первым |
| E6AE | До передачи заголовка: запись AUTO=0 или номера раздела 1–36; после lock: чтение выбранного номера |

ROM-контейнер версии 2 содержит 64 КиБ ROM-страниц, 4 КиБ BIOS и 2 КиБ
шрифта: 71680 байт. Loader не очищает бывшую область RAM-диска. Этап 0A
означает завершение загрузки ROM-страниц; MBR A/B в аппаратный header не передаётся.

Lock защищает физический диапазон 10000h–217FFh после арбитража всех
писателей. Обычный Reset около 2 секунд сохраняет lock и SRAM. Удержание
10 секунд, потеря PLL lock или включение питания снимают lock и повторяют
первичный BIOS и загрузку ROM. Записи CPU под
виртуальным ПЗУ идут в базовую RAM, как в классическом эмуляторе.

Первичный BIOS предоставляет loader API: F000 cold start, F003 open,
F006 get byte, F009 fail, F00C handoff, F00F text status (A=этап),
F012 block progress (A=номер блока, B=всего). Последние две процедуры
сохраняют A/B/X. Текстовая экранная RAM 0400–07BF, 40×24 для 601, 40×12 с парами атрибут/символ для 601A; cursor отключён.
Handoff F00C теперь заново вычисляет CRC32 всех 71680 байт ПЗУ через
физическое чтение SRAM и сравнивает с заголовком до очистки RAM/commit.
Этап 0C — `VERIFYING SRAM CRC32`; ошибка оставляет ROM незаблокированным
и останавливает CPU в resident BIOS. Заголовок версии 1 требует миграции; для выбора
601A в первом разделе должны быть текущий LOADER.BIN и P601A.ROM.

Выбор модели и байт 25 ROM-заголовка описаны в [MODELS.md](audit/MODELS.md).
Модель фиксируется до загрузки ROM и сохраняется вместе с lock при Reset.
Разметка SD и распознавание FAT12 UniDOS в Linux — в [SD-card.md](SD-card.md).

Первичный BIOS работает с HD6303 ISA независимо от выбранного E6A0.1;
выбранная ISA начинает действовать после lock. P601.SET хранит модель,
расширение, частоту и загрузочный раздел; DEL открывает редактор настроек. Длительный Reset
около 2 секунд возвращает выбранную частоту, 10 секунд повторяет первичный
BIOS без переключения питания. [Формат и меню](audit/BIOS-SETUP.md).
