# Системные BIOS и UniDOS

Эти исходники — текущая версия для FPGA Пълдина. Они хранятся в Git,
редактируются непосредственно и передаются UniAS без переписывания сборщиком.

| Исходник | Результат | Назначение |
|---|---|---|
| BIOS.ASM | build/partitions/BIOS.ROM, 4096 байт | Системный BIOS 601 |
| BIOS_A.ASM | build/partitions/BIOS_A.ROM, 4096 байт | Системный BIOS 601А |
| U.ASM / KERNELFS.INC | build/partitions/KERNEL.ROM, 8192 байта | Ядро UniDOS 3.01, нативный FAT12/FAT16 и INT EA/EB |
| FATCORE.ASM / FATOPEN.INC / FATBUFFER.INC / FATABI.INC | часть SD.ROM страницы B | Алгоритмы FAT, проверка OPEN, кэши и явные дескрипторы томов, INT E9 |
| UNIDOS.ASM | build/partitions/SHELL.CMD | Исправленная оболочка UniDOS |
| UNISHELL.ASM | build/partitions/SHELL.ROM, 8192 байта | Вся сжатая оболочка и декомпрессор в странице F |
| UNIBIOS.ASM | build/partitions/UNIBIOS.ROM, 8192 байта | UniBIOS 3.02: страница 8, монитор и шрифт |
| MEMORY.INC | — | Адреса штатных регистров/переменных |
| FONT.INC | — | Исходная таблица 256 символов, 2048 байт |
| VIDEO.ASM / FONT.INC | rtl/font_boot.mem | Тот же шрифт для первичного BIOS |

В BIOS уже внесены прямой SD boot, сохранение E6F0/E6F1, музыкальный и
PS/2 IRQ и исправления потребителей SWI-кадра. Общие обработчики находятся
в `../memory/BIOSPAGES.INC`; участки `DS` сохраняют
адреса публичных входов, reset loop и векторов. CHECKSUM считает UniAS.
В UniDOS исправлены бюджет стека COPY, новый кадр SWI и очистка GAMEBIOS/
арендованной RAM при завершении процесса.

BIOS*.ASM, U.ASM, UNIDOS.ASM и MEMORY.INC сохраняют исходную однобайтовую
кодировку исходных файлов Пълдина. Не перекодируй литералы строк в UTF-8: это изменит ПЗУ.

UNIBIOS.ASM взят из доступного исходника версии 3.02 (01-Apr-1990).
В отличие от прежнего бинарного ROM версии 3.00, вся страница собирается
из инструкций и исходной таблицы FONT.INC. Бинарные фрагменты монитора
и обходной переход в BIOS удалены. Breakpoint читает PC по смещению 9
и снимает 11 байт кадра с сохранённым E6F1. Замена `LDAA #0` на `CLRA`
в невозвращающемся входе монитора освободила байт для дополнительного INS;
шрифт остаётся по D800, checksum по D7FF, размер страницы — 8192 байта.

FONT.INC взят из `PYLDIN601-HD6303/SW/SRC/UNI/FONT.INC`; собранные
байты совпадают с `native-src/FONT.IMG`. Для загрузчика C преобразует
порядок символов в формат EBR; итоговый font_boot.mem совпадает с прежним.
Исполняемые байты в DB/бинарных include без ассемблерного исходника запрещены.

U.ASM восстановлен из `native-src/U.ASM` версии 3.01. Страница C больше
не берётся из старого бинарного ROM 3.00. Сигнатура 5AA5, штатные файловые
SWI и расположение публичных переменных сохранены. Дискетные/CHS процедуры
заменены отказом INV_DRV; A/B устанавливает служба разделов. Дополнительное
состояние FAT принадлежит ядру и заменяет второй FAT-буфер E900; handle
получает девять частных байт после прежнего тела. Опциональный FAT_RAMMAN=1
выносит FAT-кэши и два штатных файловых кэша в один банк с отдельными
проверками переноса и возвратом к обычным буферам. Файловое окно занимает
512 байт; освобождённая область хранит пять заголовков томов без heap.
Явные пользовательские буферы сохраняют прежний формат и адреса. [Форматы, ограничения, запись и тесты](../../docs/STORAGE.md).

```sh
make -f firmware/Makefile roms UNIAS=/path/to/unias
```

Все исполняемые инструкции собирает UniAS. C-инструмент `firmware-data`
сжимает уже собранный SHELL.CMD в формате оригинального Uniload,
проверяет побайтную распаковку, размеры/контрольные суммы и создаёт отчёт.
SHELLPACK.INC — производные данные из UNIDOS.ASM; код декомпрессора
полностью находится в UNISHELL.ASM. INT E3 восстанавливает всю оболочку
в RAM 1000–3710, затем загрузчик страницы A запускает её. Хвоста оболочки
в странице A больше нет. Результаты остаются в игнорируемой директории `build`.
