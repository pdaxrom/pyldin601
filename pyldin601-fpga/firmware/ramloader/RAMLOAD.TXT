ramloader / RAMLOAD.PGM

Run from the main UniDOS prompt before starting NC:
  E:RAMLOAD E:CRC16.ROM
  E:RAMCHECK
  E:RAMLOAD /L
  E:RAMLOAD /U CRC16

RAMCHECK must print:
  PASS: banked ROM CRC16 = 29B1

Use your actual drive letter instead of E:.
/L or LIST lists installed ROMs; /U NAME or UNLOAD NAME unloads one.
NAME is the eight-character name inside the ROM header.
The first successful LOAD installs the resident registry. Later commands
can run from NC or a nested shell. The registry remains until Reset.
4 modules, up to 8 SWI exports each; one 8-KiB RAMMAN bank per module.
About 1.1 KiB conventional RAM once, disposable loader buffers released.

Requires updated P601.ROM/P601A.ROM with RAMMAN PIN/UNPIN (INT E5 A=4/5).
Replace the ROM bundles on the boot partition, then perform a full reload.
No FPGA rebuild is needed. Ordinary warm Reset retains the previous ROM.

Supported file: exactly 8192 bytes, native A55A/5AA5 ROM header,
zero additive checksum, code at C000-DFFF, no writes to its own bank,
no fixed page/group assumptions. INIT gets X -> 8 persistent zero bytes,
returns result in SWI A ($06), RTS; no vector changes or external leases.
SWI handlers use the native $04-$08 result registers and return RTS.
Existing SWI services are preserved. IRQ modules need a separate ABI.

Errors (hex):
04 RAMMAN missing       50 INT EC conflict    51 Invalid ROM
52 SWI conflict        53 Duplicate name     54 All slots occupied
55 Active/changed SWI  56 First LOAD nested  57 Update ROM/RAMMAN
58 Module not found    FF Cancelled         Others: DOS/RAMMAN/INIT error.

CRC16.ROM exports INT ED, ABI 1. A=1: X -> sourceBE,lengthBE,seedBE,resultBE.
CRC-16/CCITT-FALSE, polynomial 1021; RAMCHECK tests 123456789 -> 29B1.
Full technical description: docs/RAMLOADER.md in the project.
