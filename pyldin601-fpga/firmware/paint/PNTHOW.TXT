Native Paint build from the HG PAINTSRC directory

Before CD PAINTSRC, from the HG root run HANDLES 16 and CVM\RAMLOAD /CVM.
Then run the commands below. UniAS/UniAR/UniLD come from the sibling CVM
directory. Remove an old PNTCOM.LIB if its member list has changed.
No host binary patching is required. Run PAINT.PGM after linking.
PNTBOOT.PGM/PNTCORE.PGM are internal parts, not standalone applications.

..\CVM\UNIAS -c -o PNTMAIN.OBJ PNTMAIN.ASM
..\CVM\UNIAS -c -o PNTUI.OBJ PNTUI.ASM
..\CVM\UNIAS -c -o PNTCANV.OBJ PNTCANV.ASM
..\CVM\UNIAS -c -o PNTDRAW.OBJ PNTDRAW.ASM
..\CVM\UNIAS -c -o PNTPART.OBJ PNTPART.ASM
..\CVM\UNIAS -c -o PNTPAL.OBJ PNTPAL.ASM
..\CVM\UNIAS -c -o PNTDMA.OBJ PNTDMA.ASM
..\CVM\UNIAS -c -o PNTLOAD.OBJ PNTLOAD.ASM
..\CVM\UNIAS -c -o PNTMOD.OBJ PNTMOD.ASM
..\CVM\UNIAS -c -o PNTIO.OBJ PNTIO.ASM
..\CVM\UNIAS -c -o PNTPCX.OBJ PNTPCX.ASM
..\CVM\UNIAS -c -o PNTIFF.OBJ PNTIFF.ASM
..\CVM\UNIAS -c -o PNTFILE.OBJ PNTFILE.ASM
..\CVM\UNIAS -c -o PNTDATA.OBJ PNTDATA.ASM
..\CVM\UNIAS -c -o PNTSTATE.OBJ PNTSTATE.ASM
..\CVM\UNIAS -c -o PNTSTR.OBJ PNTSTR.ASM
..\CVM\UNIAS -c -o PNTEND.OBJ PNTEND.ASM
..\CVM\UNIAS -c -o PNTCOM.OBJ PNTCOM.ASM
..\CVM\UNIAS -c -o NCKEY.OBJ NCKEY.ASM
..\CVM\UNIAS -c -D MOUSE_OBJECT -o MOUSE.OBJ MOUSE.ASM
..\CVM\UNIAR r PNTCOM.LIB PNTCOM.OBJ NCKEY.OBJ MOUSE.OBJ
..\CVM\UNIAS -o PNTBOOT.PGM PNTBOOT.ASM
..\CVM\UNILD -m PAINT.MAP -o PNTCORE.PGM @PAINT.LNK
..\CVM\UNILD -b -o PAINT.PGM PNTBOOT.PGM PNTCORE.PGM
..\CVM\UNIAS -o PNTNAT.PGM PNTNAT.ASM
..\CVM\UNIAS -o PNTRGB.PGM PNTRGB.ASM
..\CVM\UNIAS -o PNTHAM.PGM PNTHAM.ASM
