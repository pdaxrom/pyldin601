Native Paint build from the HG PAINTSRC directory

Before CD PAINTSRC run HANDLES 16 and CVM\RAMLOAD /CVM.
Use the updated UniLD with -z (fixed code extent). All .EDO/.FIO files
are ordinary UniCROSS OBJ modules; only their filename extensions differ.
The resident prefix caches both standard PGM overlays in GPU SRAM and
reloads their code without disk access; BSS and the document stay live.
PNTBOOT/PNTCORE/PNTFIO are internal components. Start PAINT.PGM.
