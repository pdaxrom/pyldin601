NC object build (host or native UniDOS)
HANDLES 16 (before RAMLOAD /CVM on native UniDOS)
Copy firmware/input/MOUSE.ASM beside these NC sources.
Copy firmware/memory/DMA.INC beside them too (NCEROW.INC uses it).
If tools are in ..\CVM, prefix commands below with ..\CVM\.

unias -o NC.PGM NC.ASM
unias -o NCELOAD.PGM NCELOAD.ASM
unias -c -o NCCOM.OBJ NCCOM.ASM
unias -c -o NCKEY.OBJ NCKEY.ASM
unias -c -o NCMOUSE.OBJ NCMOUSE.ASM
unias -c -o NCEMOUSE.OBJ NCEMOUSE.ASM
unias -D MOUSE_OBJECT -c -o MOUSE.OBJ MOUSE.ASM
unias -c -o NCEBLOCK.OBJ NCEBLOCK.ASM
unias -c -o NCEAUTO.OBJ NCEAUTO.ASM
unias -c -o NCEDIT.OBJ NCEDIT.ASM
unias -c -o NCEFILE.OBJ NCEFILE.ASM
unias -c -o NCENAV.OBJ NCENAV.ASM
unias -c -o NCEND.OBJ NCEND.ASM
unias -c -o NCESTR.OBJ NCESTR.ASM
unias -c -o NCEUI.OBJ NCEUI.ASM
unias -c -o NCEV1.OBJ NCEV1.ASM
unias -c -o NCEV2.OBJ NCEV2.ASM
unias -c -o NCEV3.OBJ NCEV3.ASM
unias -c -o NCMAIN.OBJ NCMAIN.ASM
unias -c -o NCMCAT.OBJ NCMCAT.ASM
unias -c -o NCMFILE.OBJ NCMFILE.ASM
unias -c -o NCMSTR.OBJ NCMSTR.ASM
unias -c -o NCMUI.OBJ NCMUI.ASM
unias -c -o NCMV1.OBJ NCMV1.ASM
unias -c -o NCMV2.OBJ NCMV2.ASM
unias -c -o NCMV3.OBJ NCMV3.ASM
uniar r NCUI.LIB NCCOM.OBJ NCKEY.OBJ MOUSE.OBJ
unild -m NCMAIN.MAP -o NCMAIN.PGM @NCMAIN.LNK
unild -m NCEDIT.MAP -o NCECORE.PGM @NCEDIT.LNK
unild -b -o NCEDIT.PGM NCELOAD.PGM NCECORE.PGM

Run NC.PGM with NCMAIN.PGM and NCEDIT.PGM in the same directory.
