UART [baud] - native ANSI/VT100 subset, FTDI channel B, 8N1.
Default: 19200. F10 exits; Esc is sent to the remote host.
F1 Help; F2 local echo; F3 receive file; F4 send file.
Use XON/XOFF. At CPU 1 MHz use UART 9600 (host: --baud 9600).
At 115200 prefer CPU 8 MHz. UTF-8 is not decoded.

XMODEM-CRC: 128-byte blocks, retries, Esc/F10 cancel.
Receive refuses existing files and publishes only a complete temp file.
Binary final-block padding (1A) is retained; XMODEM has no file length.
The progress byte counter includes padding and is hexadecimal.
A failed cleanup leaves UTxxxx.TMP; check the disk when reported.

Host: python3 uart_xmodem.py send source.bin --baud 19200
      python3 uart_xmodem.py receive result.bin --baud 19200
Select F3 on Pyldin for host send, F4 for host receive.
Host uses FTDI B (if01), leaving HG/channel A untouched.
