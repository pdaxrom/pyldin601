# Пълдин-601/601А для FPGA

Классический Пълдин для платы Z-pdaXrom-TV / hardware-lcd,
Lattice MachXO2-7000HC, с выбором модели 601/601А и MC6800/HD6303 ISA.
Рабочая частота CPU — 1/2/4/8 МГц. Внешняя SRAM 2 МиБ включает
базовую RAM, ROM/font, 888 КиБ банкового ОЗУ и 1 МиБ графической памяти.

Расширения общие для обеих моделей:

- 320×200 с 256 программируемыми цветами и HAM8;
- HAM8-фон с RGB222 наложением без изменения цвета справа от объектов;
- аппаратный FILL/COPY/прозрачный COPY и VBL-переключение страниц;
- GAMEBIOS: графика, текст, спрайты с обрезкой, очередь AY и нотные эффекты;
- AY-3-8910 с программируемым master и независимым музыкальным IRQ;
- PS/2, ROM-перевод в старые клавиатурные коды, native repeat и raw capture;
- нативные SD-разделы FAT12/FAT16 с 32-битными секторами, MBR/extended EBR и HG-диск папки хоста.

ROM/RAM-диски и i8272 удалены. UniDOS находится в ROM; его оболочка
сжата в одну страницу UniShell. Штатные видеорежимы и BIOS-вызовы
сохранены; новые возможности приложение вызывает явно. Физический
HD6303-компьютер Lilith — отдельный проект, ISA здесь выбирается в FPGA.

## Запуск

Для новой карты [images/sd.img](images/README.md) содержит оба ROM,
загрузчик, программы/тесты на B и распакованные архивы прежнего ROM-диска
на C. Общую используемую карту обновлять через полную резервную копию,
сохраняя чужие разделы и настройки; инструкция — в документации сборки.

DEL открывает первичный BIOS Setup. У обеих моделей bootstrap-консоль
одинаковая, 40×24; после загрузки native BIOS 601А включает свой экран.
Короткий Reset меняет скорость, удержание около 2 с возвращает native
BIOS без перечитывания ROM; 10 с повторяет полный bootstrap после отпускания.

```text
B:SDKTEST
B:ARKANOID
B:XONIX
B:HVIEW B:LENA.IFF
B:YPLAY B:DEMOH5.YM /L
B:HG
```

Новые игры/просмотрщики/плеер требуют HD6303 и согласованных ROM/FPGA;
для игр рекомендуются 4/8 МГц. После HG использовать сообщённую им букву
(обычно D при SD A/B/C). [Управление, рекорды и список фонов](docs/ARCADE.md).

## Сборка

Исполняемые исходники хранятся в firmware и собираются настоящим UniAS.
UniBIOS 3.02 собирается целиком из ASM/FONT.INC; Python-ассемблера и
генерации CPU-инструкций при сборке нет. C-инструмент создаёт данные и
упаковывает уже собранную оболочку. Python используется для тестов/образов.

```sh
make -f firmware/Makefile all UNIAS=/path/to/hd6303-toolchain/unias
make test UNIAS=/path/to/hd6303-toolchain/unias
```

Текущая graphics v6: 5323/6864 LUT, 23/26 EBR, 1/2 PLL;
PLL даёт system 24 МГц и SRAM 96 МГц. Подробные ограничения и отдельные
цели проверки — [BUILD.md](docs/BUILD.md). Происхождение CPU-ядра и
лицензия сохранены в [vendor](vendor/README.md).
