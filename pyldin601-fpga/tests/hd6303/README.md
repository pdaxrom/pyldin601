# Тесты HD6303 для UniDOS

При холодном запуске выбрать модель 601/601A, затем CPU **2 — HD6303**.
Оба меню ждут по 10 секунд. В UniDOS выполнить:

```text
B:
HDTEST
HDMUL
HDSLEEP
```

| Программа | Проверка |
|---|---|
| HDTEST.CMD | 740 случаев: LSRD/ASLD, XGDX, ABX, MUL, AIM/OIM/EIM/TIM, ADDD/SUBD/LDD/STD, HD CPX, direct JSR, PSHX/PULX, BRN; результаты, CCR, все адресации, память, байты/баланс стека |
| HDMUL.CMD | Все 65536 беззнаковых A×B; ожидаемый результат считается сложением байтов, проверяются C=bit7 произведения и сохранность H/I/N/Z/V, X и SP |
| HDSLEEP.CMD | 32 SLP с разрешённым IRQ, 32 с маскированным IRQ; обычный PAL IRQ, сохранность D/X/CCR/SP |

Успех — `PASS`, ошибка — `FAIL` с номером случая или входными данными.
Программы возвращаются в UniDOS, файловые операции не выполняют.
При выбранном MC6800 показывают `SKIP` до первой расширенной команды.
HDTEST сохраняет/восстанавливает `$80/$81` и маскирует IRQ на время их
использования. HDMUL оставляет IRQ разрешённым; в маскированной половине
HDSLEEP часы могут немного отстать. TRAP/NMI проверяются отдельными
RTL-тестами: эти программы не меняют векторы и locked ROM.

## Сборка и образ SD

Из каталога `pyldin601-fpga`:

```sh
make hd6303-apps UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
make test-hd6303-apps UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
make hd6303-test-image UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
```

Три CMD, три развёрнутых ASM и README.TXT создаются в `build/hd6303-apps`.
HDTEST.ASM генерируется из шаблона и векторов с независимыми формулами
результатов/флагов; UniAS выполняет фактическую сборку всех программ.
`tests.json` связывает номер ошибки с командой, входами и ожидаемым результатом.

`build/sd-hd6303-tests.img` — новый образ 20 МиБ на основе
`build/sd-models/sd-after.img`, программы/исходники добавлены в корень B.
MBR, раздел ROM/LOADER, диск A, геометрия и существующие файлы B сохраняются.
`build/sd-hd6303-tests.json` содержит SHA образа и каждого файла.
`HD_TEST_SD=...` позволяет выбрать другую резервную копию.
Инструмент отказывается перезаписывать существующий выходной образ;
перед повторной генерацией нужно перенести прежний результат.
Физическую SD-карту эта команда не записывает.

## Проверки 4 октября 2026

- C-эталон: HDTEST 740 случаев и HDMUL 65536 произведений — PASS.
- Настоящий VHDL CPU: все три собранных CMD — PASS, включая 64 SLP;
  срабатывания IRQ проходят через стек и RTI в минимальных консольных stubs.
- Все три CMD в MC6800 корректно пропускаются; испорченный результат MUL
  в C и испорченный ожидаемый CCR в RTL обнаруживаются как FAIL.
- Оригинальные BIOS 601/601A и UniDOS в C-модели: все три программы
  загружаются с B, выводят PASS, затем DIR возвращает приглашение.
- FAT12: фрагментированное выделение, соседние packed FAT entries,
  дубли имён, полная файловая система, различающиеся FAT-копии,
  сохранность существующих файлов и других разделов — PASS.

Журналы — `build/hd-tests-apps.log`, `build/hd6303-apps/*-rtl.log`,
`build/hd-tests-unidos.log`, `build/hd-tests-unidos-a.log`.
Воспроизведение проверки штатного UniDOS после подготовки образа:

```sh
make fixtures
cc -O2 -I../pyldin601/src tests/test_hd6303_unidos.c -o build/test_hd6303_unidos
build/test_hd6303_unidos build/sd-hd6303-tests.img
build/test_hd6303_unidos build/sd-hd6303-tests.img 601a
```

Программы на физической плате пока не запускались. Полная проверка
электрических сигналов SRAM/SD этими симуляциями не заявляется.
