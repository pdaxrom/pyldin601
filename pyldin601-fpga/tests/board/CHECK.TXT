PYLDIN BOARD CHECK - 2026-10-18

Use a fresh, dedicated BOARDCHK directory. Keep the supplied inputs here.
The JOBs create/replace their compiled outputs and TEST.LIB here.
CVMTEST creates and deletes CVMIO.DAT here. Save editor/paint/UART files
in this directory only. Do not use the jobs in a directory with user data.
Nothing formats disks or writes raw memory. RAMPAGE is NOT used.

START FROM THE MAIN UniDOS PROMPT, before NC, not from another JOB:

  E:
  CD \BOARDCHK
  HANDLES 16
  E:\REL1017\CVM\RAMLOAD /CVM
  CHECK E:\REL1017 E:\REL1017\CVM E:

Replace E: with the HG drive. Program/CVM arguments must be directories,
with no trailing backslash. For the installed SD release use instead:

  HANDLES 16
  C:\CVM\RAMLOAD /CVM
  CHECK B: C:\CVM E:

HANDLES and first RAMLOAD must run BEFORE the JOB, in the main shell.
There are two nested JOBs: CHECK calls AUTO and resumes on its EOF.
AUTO B: C:\CVM runs just the core tests, without starting the editors.
It pauses between tests so results stay visible.
Both CHECK and AUTO keep your current video mode.
The final CHECK argument is the work drive. CHECK restores that drive
and its \BOARDCHK directory after every interactive application.

CORE TESTS

01 RAMMAN: PASS: RAM allocator, 64 KiB, SWI/IRQ; nonzero IRQ counter.
02 DMA: PASS: DMA 8K copy/fill, PAL restored.
03 VM: CVM HELLO PASS, CVM TEST PASS (arithmetic, recursion, file IO).
04 C compiler: There were 0 errors in compilation.
05 Assembler/CMD: CVM HELLO PASS from freshly compiled OUT.CMD.
06 ASM: both object assemblies finish without errors.
07 Direct linking: OBJECT PASS.
08 Library: TEST.LIB contains OHELP.
09 Linking from library: OBJECT PASS.
10 C objects: both compilations and both assemblies have no errors.
11 Native objects: both assemblies have no errors.
12 MIXAPP.PGM: C MIXED PASS (C -> native -> C callbacks/recursion).
13 NENTRY.PGM: C MIXED PASS, C ABI PASS (native -> arbitrary C functions).

At each JAxx READY, inspect the actual program output and compare it
with the numbered list above, then press a key. Expected is guidance.
Output goes directly through BIOS; UniDOS > redirection does not record
most diagnostics. Photograph a failure before advancing.
JOB has no IF/ERRORLEVEL: an error does NOT stop later commands.
The final END means the checklist ended; it does NOT mean all tests PASS.
If a tool failed, do not count a later run of an old output as success.
Stop with Break, capture the error, then repeat in a fresh test directory.

INTERACTIVE CHECK (CHECK.JOB launches these in order)

NC: MANY has 128 files. Scroll through 63/64 in both directions, PgUp/Dn.
LONG.TXT has 4096 lines (over 200 KiB). F4: navigate to the end and back,
select/copy/paste, Undo/Redo, search/replace, save to a TEST file, reopen.
Do not change original test sources. Ctrl+F1/F2 must show drive lists.
Check F1..F10, dialogs/progress, mouse, command/input-dialog caret.
Run PLAIN.PGM; NC must return. Ctrl+O -> EXIT must return to NC.
F10 leaves NC and the JOB continues to the PAINT instructions.

PAINT: F6 chooses the format. Check all available formats, F4/F5 windows,
palette, drawing, text, fill, selection/zoom and Undo/Redo. Save/reopen
TEST.PCX and TEST.IFF in BOARDCHK. F10 must restore the previous video.

UART: 9600 works at 1 MHz. F1 opens help, Esc closes it; F2 local echo
lets you check keyboard without a peer. F3/F4 transfers require the host.
Use UART 115200 only at 8 MHz. F10 returns to the JOB.
UART/PAINT/NC file dialogs initially inherit the current directory.

HD6303 ONLY: HDCHECK B: E: (or HDCHECK E:\REL1017 E:).
This separately starts SDKTEST, GFX, ARKANOID, XONIX, HVIEW and YPLAY.
SDKTEST must show PASS: SDK tiles and scrolling. Other stages are visual.
Games may save their own settings/scores beside their installed files.
Do not run HDCHECK in MC6800 mode; test HD-only program refusal manually.

MATRIX

Repeat CHECK for 601/601A x MC6800/HD6303 x 1/8 MHz, recording results.
Select model/CPU in Setup before each run; cold-boot and load the VM again.
Do not reset during a JOB. NC uses the mode in which it was launched.
601: MODE 40. 601A: MODE 40, MODE 40 23 (colour), MODE 80.
Repeat NC/PAINT checks in each supported video mode. No exotic modes.
The jobs do not automate Reset/Setup, RAMMAN exhaustion or crash recovery.
Check those separately using docs/RELEASE.md and docs/NC_EDITOR.md.

When run in HG, file tests exercise HG; DIR A:/B:/C: checks SD reads.
For actual SD writes, copy this whole directory to B:\BOARDCHK using NC,
switch there and repeat with CHECK B: C:\CVM B:. Programs may
still be read from HG, but all compilations and CVMIO use the SD.
Do not overwrite an existing directory containing user files.

HOST READBACK

Keep OUT.CMD, OMAIN.OBJ, OHELP.OBJ, PLAIN.PGM, OBJLIB.PGM,
TEST.LIB, MIX*.ASM/OBJ/PGM, MINLINE.ASM/OBJ, MNATIVE.OBJ, NENTRY.OBJ/PGM.
