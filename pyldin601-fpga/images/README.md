# Готовый образ SD для Пълдин-601/601A

[`sd.img`](sd.img) — текущий образ от 4 октября 2026 для Z-pdaXrom-TV,
конфигурация hardware-lcd. Он побайтно совпадает с проверенным чтением
обновлённой физической карты. Сборка и распаковка не нужны.

Размер — 20 МиБ (20971520 байт). В образ входят MBR и все три раздела;
он помещается на SD-карту не меньше этого размера. Остальная ёмкость
карты в этой разметке не используется.

| Раздел | Содержимое | Начальный LBA | Размер |
|---|---|---:|---:|
| 1 | FAT16: LOADER.BIN, P601.ROM, P601A.ROM, P601.CFG | 2048 | 16 МиБ |
| 2 / A | FAT12: системный диск с UniDOS | 34816 | 720 КиБ |
| 3 / B | FAT12: HDTEST, HDMUL, HDSLEEP, ASM-исходники, README.TXT | 36864 | 1,44 МиБ |

Контрольная сумма образа записана в [`SHA256SUMS`](SHA256SUMS).
[`sd.json`](sd.json) содержит разметку и контрольные суммы разделов и файлов.
Образ предназначен для [текущей прошивки FPGA](../audit/HD6303.md#проверки-и-сборка).

## Запись в Linux

Из корня репозитория:

```sh
cd pyldin601-fpga/images
sha256sum -c SHA256SUMS
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
```

Определи устройство карты и отмонтируй все её смонтированные разделы.
Замени `/dev/sdX` ниже на устройство **всей карты**, например `/dev/sdf`.
Запись заменяет MBR и все три раздела данными образа.

```sh
sudo dd if=sd.img of=/dev/sdX bs=4M status=progress conv=fsync
```

Дождись завершения записи, затем верни карту в плату.

## Запись в macOS

Из корня репозитория:

```sh
cd pyldin601-fpga/images
shasum -a 256 -c SHA256SUMS
diskutil list
```

Замени `diskN` на номер SD-карты, найденный в списке:

```sh
diskutil unmountDisk /dev/diskN
sudo dd if=sd.img of=/dev/rdiskN bs=4m
sync
diskutil eject /dev/diskN
```

## Первый запуск

Установи SD в плату с текущей прошивкой FPGA и включи питание. Первое меню
выбирает модель: `1` — 601, `2` — 601A. Второе выбирает CPU: `1` — MC6800,
`2` — HD6303 ISA. Enter принимает значение по умолчанию; оба меню ждут
по 10 секунд. Без ввода запускаются 601 и MC6800, затем UniDOS с диска A.

Для тестов выбрать CPU **2 — HD6303**, после ввода даты/времени выполнить
в UniDOS по очереди:

```text
B:HDTEST
B:HDMUL
B:HDSLEEP
```

Ожидается PASS и возврат в UniDOS; в MC6800 программы выводят SKIP.
Точный файл `sd.img` прошёл программную загрузку через SD/FAT для всех
четырёх сочетаний 601/601A и MC6800/HD6303, включая инициализацию
электронного диска и сохранение ROM/диска при warm reset. В C-модели
штатного UniDOS обеих моделей все три теста загружаются с B, выводят PASS,
затем DIR возвращает приглашение. Собранные CMD также проверены на RTL CPU;
исполнение этих программ на физической плате пока не подтверждено.
[Покрытие и сборка тестов](../tests/hd6303/README.md).

Разметка, сигнатура диска A и подготовка новых образов описаны в
[SD-card.md](../SD-card.md).
