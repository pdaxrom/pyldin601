# SD-образ 2026.10.17-rc1

Начальный образ для новой карты: 36 МиБ, обе модели 601/601А,
UniBIOS 3.02, UniDOS, NC с потоковым редактором, PAINT с мышью,
UART/ANSI/XMODEM, игры и нативные инструменты C/ассемблера.

Это кандидат первого релиза. Автоматические проверки пройдены;
18 октября 2026 года пользователь подтвердил прохождение проверок
BOARDCHK на плате. Состав, сценарии повторной проверки и ограничения —
[RELEASE.md](../docs/RELEASE.md).

| Раздел | LBA | Секторов | Содержимое |
|---|---:|---:|---|
| 1, FAT16 | 2048 | 32768 | LOADER.BIN, P601.ROM, P601A.ROM, P601.SET, P601.CFG |
| 2, FAT12 | 34816 | 1440 | A: исходный системный диск с родным загрузочным сектором |
| 3, FAT12 | 36864 | 2880 | B: NC, PAINT, UART, игры, просмотрщики, плееры, диагностика |
| 4, FAT12 | 40960 | 32400 | C: распакованное старое ПО, ARCHIVES, новые инструменты в CVM |

[SHA256SUMS](SHA256SUMS) проверяет образ, [sd.json](sd.json) описывает
каждый раздел и файл. Приложения, обе системные ROM и SD loader собраны
вместе. Все три файла NC и все четыре файла PAINT обновлять целиком.
Пользовательские файлы с физической общей карты в образ не входят.

## Запуск

Нужна FPGA с общим DMA, программным PS/2-портом мыши, загружаемым
указателем и UART. Хеш совместимого JED находится в sd.json и полном
релизном комплекте. Настройки новой карты: 601/HD6303/1 МГц/AUTO.
DEL открывает Setup. Для игр рекомендуются 4/8 МГц.

```text
B:NC
B:PAINT
B:UART 9600
B:ARKANOID
B:XONIX
B:YPLAY B:DEMOH5.YM /L
B:HG
```

После HG использовать сообщённую букву. Нативная разработка из основной
оболочки UniDOS, перед запуском NC:

```text
C:
CD \CVM
HANDLES 16
RAMLOAD /CVM
HELLO
CVMTEST
```

VM выбирается по CPU. Оба ROM интерпретатора, SYSTEM.H и инструменты
должны быть одной версии. [Подробности](../docs/CVM.md).

## Новая карта

Проверка файлов:

```sh
cd images
shasum -a 256 -c SHA256SUMS
```

На Linux определить новое устройство через `lsblk -o NAME,SIZE,MODEL,MOUNTPOINTS`
и отмонтировать его разделы. `/dev/sdX` ниже — пример, заменить на
проверенное устройство всей новой карты:

```sh
sudo dd if=sd.img of=/dev/sdX bs=4M conv=fsync status=progress
```

Прочитать первые 37748736 байт назад и сравнить с sd.img, затем вернуть
карту в плату. Короткий Reset меняет частоту, warm Reset сохраняет ROM
в SRAM; новый ROM-комплект требует полного bootstrap.

## Существующая общая карта

Начальный образ заменяет MBR и данные затронутых разделов. Для используемой
общей карты получить полную резервную копию и обновлять именованные
файлы, сохраняя разметку, настройки, рекорды и другие тома. LBA и буквы
на ней могут отличаться от приведённых выше.
[Подготовка и миграция](../docs/BUILD.md), [разметка](../docs/SD-CARD.md).

Полный релизный каталог дополнительно содержит JED и отчёты, boot-файлы,
HG и контрольные суммы; его создаёт `tools/package_release.py`.
Программа работает только с обычными файлами и не записывает карту.
