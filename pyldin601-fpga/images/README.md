# Готовый образ SD для Пълдин-601/601A

[`sd.img`](sd.img) — текущий образ от 9 октября 2026 для Z-pdaXrom-TV,
конфигурация hardware-lcd. На B находятся GFX и нативный HD6303 VIEW.PGM,
их ASM-исходники, PALCOEF.ASM, инструкции и стандартные PCX-примеры. VIEW
использует все 256 RGB888-цветов файла и восстанавливает палитру при ESC.
Также добавлены SPRITES.PGM/ASM и SPRHOWTO.TXT: три прозрачных спрайта
с аппаратным COPY, восстановлением фона и переключением кадров по VBL.
Для `B:SPRITES` нужны HD6303 и графический интерфейс v3. Текущий VIEW
принимает v2 и выше.
HAM.PGM/ASM и HAMHOWTO.TXT обновлены для HAM8 и графического интерфейса
v5: ESC возвращает UniDOS с восстановлением палитры; HAM6/SPACE удалены.
Добавлены CLIPSPR.PGM/ASM, GFXCLIP.ASM и CLIPHOW.TXT для обрезки спрайтов,
а также AY.PGM/ASM и AYHOWTO.TXT для трёхканальной мелодии.
[HAM8](../audit/HAM.md), [обрезка](../audit/SPRITE-CLIPPING.md),
[AY](../audit/AY.md).
Добавлены HVIEW.PGM/ASM, HVIEWHOW.TXT и LENA.IFF: загрузчик HAM8 IFF ILBM
для HD6303/v5. `B:HVIEW B:LENA.IFF`, ESC возвращает UniDOS.
[C-конвертер JPEG/PNG и инструкция](../audit/HAM-VIEWER.md).

Обе ROM обновлены дополнительной страницей B: прямой SD-драйвер INT17
и INT E0 для графики/спрайтов/звука. Аппаратный i8272 удалён из нового
кандидата FPGA. Страницу собирает UniAS с CHECKSUM; родные BIOS и остальные
ROM-страницы сохранены. [FPGA BIOS](../audit/FPGA-BIOS.md).
P601.SET образа: 601, HD6303 EXTENSION Y, 1 МГц. MBR, диск A, настройки
и остальные файлы B сохранены. Обе ROM на физической карте обновлены,
FPGA прошита с FLASH Verify; пользователь подтвердил загрузку, DIR с A/B,
полный Reset, мелодию AY через HG и возврат по ESC. Физическая запись
файла новым SD-драйвером отдельно не проверялась. Предыдущую FPGA нельзя заменять без обновления
обеих ROM на SD. Для VIEW нужны HD6303 и графическое устройство v2+.

В предыдущую версию на основе проверенного чтения карты добавлен P601.SET
с настройками 601, MC6800, 1 МГц. На B добавлены HG.PGM, HGTIME.PGM, HG.ASM и HGHOWTO.TXT; прежние файлы
boot, MBR, A и остальные файлы B сохранены;
boot-раздел физической карты при обновлении совпал с образом. После SAVE
на плате P601.SET содержит выбранные пользователем настройки. Текущие
A/B физической карты сохранены и отличаются от A/B этого готового образа.
Сборка и распаковка не нужны.

Размер — 20 МиБ (20971520 байт). В образ входят MBR и все три раздела;
он помещается на SD-карту не меньше этого размера. Остальная ёмкость
карты в этой разметке не используется.

| Раздел | Содержимое | Начальный LBA | Размер |
|---|---|---:|---:|
| 1 | FAT16: LOADER.BIN, P601.ROM, P601A.ROM, P601.CFG, P601.SET | 2048 | 16 МиБ |
| 2 / A | FAT12: системный диск с UniDOS | 34816 | 720 КиБ |
| 3 / B | FAT12: HDTEST, HDMUL, HDSLEEP, HG, HGTIME, GFX, VIEW, HAM, CLIPSPR, AY, HVIEW, LENA.IFF, PCX-примеры, ASM и инструкции | 36864 | 1,44 МиБ |

Контрольная сумма образа записана в [`SHA256SUMS`](SHA256SUMS).
[`sd.json`](sd.json) содержит разметку и контрольные суммы разделов и файлов.
Образ предназначен для [прошивки с первичным BIOS](../audit/BIOS-SETUP.md)
и текущим кандидатом FPGA с программным SD. Поддержка P601.SET сохраняется.

## Запись в Linux

Из корня репозитория:

```sh
cd pyldin601-fpga/images
sha256sum -c SHA256SUMS
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
```

Определи устройство карты и отмонтируй все её смонтированные разделы.
Замени `/dev/sdX` ниже на устройство **всей карты**, например `/dev/sdf`.
Запись заменяет MBR и все три раздела данными образа.

```sh
sudo dd if=sd.img of=/dev/sdX bs=4M status=progress conv=fsync
```

Дождись завершения записи, затем верни карту в плату.

## Запись в macOS

Из корня репозитория:

```sh
cd pyldin601-fpga/images
shasum -a 256 -c SHA256SUMS
diskutil list
```

Замени `diskN` на номер SD-карты, найденный в списке:

```sh
diskutil unmountDisk /dev/diskN
sudo dd if=sd.img of=/dev/rdiskN bs=4m
sync
diskutil eject /dev/diskN
```

## Первый запуск

После включения новый BIOS показывает сохранённую конфигурацию и ждёт
DEL 10 секунд. Без ввода запускаются 601, HD6303 ISA, 1 МГц и UniDOS с A.
DEL открывает меню: MODEL, CPU HD6303 EXTENSION и CPU FREQ; стрелки
меняют строку/значение. SAVE AND BOOT сохраняет настройки, BOOT WITHOUT
SAVE применяет их на текущий запуск, EXIT AND BOOT отменяет изменения.
Без действительного P601.SET меню открывается сразу.

CPU HD6303 EXTENSION Y уже выбран по умолчанию. После ввода
даты/времени выполнить в UniDOS по очереди:

```text
B:HDTEST
B:HDMUL
B:HDSLEEP
B:VIEW B:FRACTAL.PCX
B:SPRITES
B:HAM
B:CLIPSPR
B:AY
```

Ожидается PASS и возврат в UniDOS; в MC6800 программы выводят SKIP.
Точный файл `sd.img` прошёл программную загрузку через SD/FAT для всех
четырёх сочетаний 601/601A и MC6800/HD6303, включая инициализацию
электронного диска и сохранение ROM/диска при warm reset. В C-модели
штатного UniDOS обеих моделей все три теста загружаются с B, выводят PASS,
затем DIR возвращает приглашение. Собранные CMD также проверены на RTL CPU;
исполнение этих программ на физической плате пока не подтверждено.
[Покрытие и сборка тестов](../tests/hd6303/README.md).

Разметка, сигнатура диска A и подготовка новых образов описаны в
[SD-card.md](../SD-card.md).

## Удалённый диск HG

Собери C-сервер командой `make hg-host` и запусти
`build/hg-host/hgfsd --directory /path/to/files`, затем
в UniDOS выполни `B:HG`. Программа устанавливает первый свободный диск
(обычно E:) и синхронизирует время. `B:HGTIME` обновляет только время.
Обе PGM работают и без расширения HD6303. Нужна FPGA-прошивка с HG;
копирование PGM на прежнюю SD-карту не обновляет FPGA.
Папка автоматически обновляет образ без перезапуска сервера; очередной
DIR/COPY в UniDOS видит изменения. Для Linux есть сервис `p601-hg`.
[Запуск, FAT12, FTDI/JTAG и ограничения](../host/hg/README.md).
8 октября HG-программы записаны на B физической SD и проверены прямым
чтением; настройки, A, прежние файлы B и дополнительные разделы сохранены.
Образ в репозитории сохраняет стандартную разметку и настройки по умолчанию.

HG.PGM/HGTIME.PGM на B обновлены для HG v2 с пакетами до 32 байт и TCK
1 МГц. Нужны новая FPGA и текущий демон; на FPGA без v2 новый PGM выбирает
v1, старый PGM работает с новым демоном. Физическая карта этим обновлением
не записывалась. [Обмен, совместимость и проверки](../audit/HG.md).

Для C-демона обновлена инструкция B:HGHOWTO.TXT в готовом образе;
MBR, загрузочный раздел, A и содержимое остальных файлов B сохранены.
Для правильного цвета начальной палитры RGB332 нужна FPGA-сборка с исправленным
порядком PAL-ROM. Текущий VIEW дополнительно требует порта программируемой
палитры версии 2; стандартные PCX-файлы менять не нужно.
[Синтез и проверка EBR](../audit/PCX-VIEWER.md).

Графический viewport масштабирует логический кадр в окно PAL 48 мкс × 264 строки
поля. Само масштабирование не меняет формат SD. Для нового прямого SD-драйвера
обе ROM физической карты требуют обновления. [Проверки](../audit/VIDEO-VIEWPORT.md).
