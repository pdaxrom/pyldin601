# Готовый SD-образ Пълдина

`sd.img` — 36 МиБ для новой карты: загрузчик, оба ROM 601/601А,
UniBIOS 3.02 из исходников, сжатая UniShell, GAMEBIOS/RAMMAN,
графические и музыкальные приложения, Арканоид и Xonix.
SHA256 находится в [SHA256SUMS](SHA256SUMS), состав — в [sd.json](sd.json).

| Раздел | Начальный LBA | Секторов | Назначение |
|---|---:|---:|---|
| 1, FAT16 | 2048 | 32768 | LOADER.BIN, P601.ROM, P601A.ROM, P601.SET, P601.CFG |
| 2, FAT12 | 34816 | 1440 | A: при AUTO, прежние системные файлы |
| 3, FAT12 | 36864 | 2880 | B: тесты, HG, графика/музыка и игры с исходниками |
| 4, FAT12 | 40960 | 32400 | C: распакованное ПО бывшего ROM-диска, утилиты разделов |

На используемой общей карте номера/LBA могут отличаться: например,
пользовательский C: может находиться на SD0:PART16. Готовый образ не
содержит текущие файлы/рекорды и разделы других машин с этой карты.
Прямая запись этого начального образа заменяет MBR и затронутые данные;
для существующей общей карты использовать полную копию и миграцию.
[Разметка](../docs/SD-CARD.md), [подготовка обновлений](../docs/BUILD.md).

## Совместимая FPGA и запуск

Нужна текущая FPGA: P601BOOT v2, банковая RAM E6F0/E6F1, audio E690–E69F,
raw PS/2 v2 и graphics v6 для Xonix. Первый BIOS всегда HD6303/4 МГц;
сохранённая модель/ISA/скорость начинают действовать при handoff.
Новый образ по умолчанию выбирает 601/HD6303/1 МГц/AUTO.
DEL меняет настройки, для игр рекомендуются 4/8 МГц.
[Процесс загрузки](../docs/BOOT.md), [регистры](../docs/REGISTERS.md).

```text
DIR A:
DIR B:
DIR C:
B:SDKTEST
B:ARKANOID
B:XONIX
B:HVIEW B:LENA.IFF
B:YPLAY B:DEMOH5.YM /L
B:HG
```

HG сообщает букву, обычно D:. SPACE/ESC у проигрывателя управляют
паузой/выходом. Игры показывают рекорды и ввод имени в графике;
SPACE/Enter из таблицы начинает раунд, ESC из таблицы возвращает UniDOS.
Рекорды сохраняются рядом с PGM в DAT/BAK. XONIX.CFG задаёт до десяти
HAM8 IFF по порядку уровней; список повторяется, старт использует кэш
без паузы музыки. [Игры и конфигурация](../docs/ARCADE.md).

## Запись новой карты на Linux

Проверить SHA из images:

```sh
(cd images && sha256sum -c SHA256SUMS)
lsblk -o NAME,SIZE,MODEL,MOUNTPOINTS
```

Отмонтировать разделы выбранной карты. `/dev/sdX` ниже — пример имени
**всей карты**, заменить его на проверенное устройство своей новой карты:

```sh
sudo dd if=images/sd.img of=/dev/sdX bs=4M conv=fsync status=progress
sync
```

После записи прочитать первые 37748736 байт обратно и сравнить с sd.img,
затем вернуть карту в плату. Не использовать эту команду поверх общей
карты с нужными разделами; процедуры миграции работают с её полным
обычным образом и сохраняют настройки/неизменяемые тома.

## Обновление приложений в обычном образе

```sh
make game-apps UNIAS=/path/to/hd6303-toolchain/unias
python3 tools/install_game.py --image card-before.img --output card-games.img
```

Установщик обновляет ROM и именованные файлы B, сохраняя другие файлы,
рекорды, XONIX.CFG, настройки и остальные разделы. `--apps-only` сохраняет
весь boot-раздел и обновляет только приложения. Это создание файла,
не запись реального устройства. Для новой ROM-версии при установке
нужен полный bootstrap; warm Reset не перечитывает ROM с SD.
