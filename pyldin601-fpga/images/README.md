# Готовый образ SD для Пълдин-601/601A

[`sd.img`](sd.img) — текущий образ от 9 октября 2026 для Z-pdaXrom-TV,
конфигурация hardware-lcd. На B добавлены GFX.PGM, GFX.ASM и GFXHOWTO.TXT;
MBR, boot-раздел, A и прежние файлы B сохранены. Графическое демо требует
[новой FPGA-прошивки RGB332](../audit/GRAPHICS.md); первичный BIOS и ROM не менялись.
Физическая SD после этого дополнения не обновлялась.

В предыдущую версию на основе проверенного чтения карты добавлен P601.SET
с настройками 601, MC6800, 1 МГц. На B добавлены HG.PGM, HGTIME.PGM, HG.ASM и HGHOWTO.TXT; прежние файлы
boot, MBR, A и остальные файлы B сохранены;
boot-раздел физической карты при обновлении совпал с образом. После SAVE
на плате P601.SET содержит выбранные пользователем настройки. Текущие
A/B физической карты сохранены и отличаются от A/B этого готового образа.
Сборка и распаковка не нужны.

Размер — 20 МиБ (20971520 байт). В образ входят MBR и все три раздела;
он помещается на SD-карту не меньше этого размера. Остальная ёмкость
карты в этой разметке не используется.

| Раздел | Содержимое | Начальный LBA | Размер |
|---|---|---:|---:|
| 1 | FAT16: LOADER.BIN, P601.ROM, P601A.ROM, P601.CFG, P601.SET | 2048 | 16 МиБ |
| 2 / A | FAT12: системный диск с UniDOS | 34816 | 720 КиБ |
| 3 / B | FAT12: HDTEST, HDMUL, HDSLEEP, HG, HGTIME, GFX, ASM-исходники и инструкции | 36864 | 1,44 МиБ |

Контрольная сумма образа записана в [`SHA256SUMS`](SHA256SUMS).
[`sd.json`](sd.json) содержит разметку и контрольные суммы разделов и файлов.
Образ предназначен для [прошивки с первичным BIOS](../audit/BIOS-SETUP.md)
и совместим с предыдущей прошивкой, которая игнорирует P601.SET.

## Запись в Linux

Из корня репозитория:

```sh
cd pyldin601-fpga/images
sha256sum -c SHA256SUMS
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
```

Определи устройство карты и отмонтируй все её смонтированные разделы.
Замени `/dev/sdX` ниже на устройство **всей карты**, например `/dev/sdf`.
Запись заменяет MBR и все три раздела данными образа.

```sh
sudo dd if=sd.img of=/dev/sdX bs=4M status=progress conv=fsync
```

Дождись завершения записи, затем верни карту в плату.

## Запись в macOS

Из корня репозитория:

```sh
cd pyldin601-fpga/images
shasum -a 256 -c SHA256SUMS
diskutil list
```

Замени `diskN` на номер SD-карты, найденный в списке:

```sh
diskutil unmountDisk /dev/diskN
sudo dd if=sd.img of=/dev/rdiskN bs=4m
sync
diskutil eject /dev/diskN
```

## Первый запуск

После включения новый BIOS показывает сохранённую конфигурацию и ждёт
DEL 10 секунд. Без ввода запускаются 601, MC6800, 1 МГц и UniDOS с A.
DEL открывает меню: MODEL, CPU HD6303 EXTENSION и CPU FREQ; стрелки
меняют строку/значение. SAVE AND BOOT сохраняет настройки, BOOT WITHOUT
SAVE применяет их на текущий запуск, EXIT AND BOOT отменяет изменения.
Без действительного P601.SET меню открывается сразу.

Для тестов выбрать **CPU HD6303 EXTENSION Y**, загрузиться, после ввода
даты/времени выполнить в UniDOS по очереди:

```text
B:HDTEST
B:HDMUL
B:HDSLEEP
```

Ожидается PASS и возврат в UniDOS; в MC6800 программы выводят SKIP.
Точный файл `sd.img` прошёл программную загрузку через SD/FAT для всех
четырёх сочетаний 601/601A и MC6800/HD6303, включая инициализацию
электронного диска и сохранение ROM/диска при warm reset. В C-модели
штатного UniDOS обеих моделей все три теста загружаются с B, выводят PASS,
затем DIR возвращает приглашение. Собранные CMD также проверены на RTL CPU;
исполнение этих программ на физической плате пока не подтверждено.
[Покрытие и сборка тестов](../tests/hd6303/README.md).

Разметка, сигнатура диска A и подготовка новых образов описаны в
[SD-card.md](../SD-card.md).

## Удалённый диск HG

Запусти на хосте демон `host/hg/hgfsd.py --directory /path/to/files`, затем
в UniDOS выполни `B:HG`. Программа устанавливает первый свободный диск
(обычно E:) и синхронизирует время. `B:HGTIME` обновляет только время.
Обе PGM работают и без расширения HD6303. Нужна FPGA-прошивка с HG;
копирование PGM на прежнюю SD-карту не обновляет FPGA.
[Запуск, FAT12, FTDI/JTAG и ограничения](../host/hg/README.md).
8 октября HG-программы записаны на B физической SD и проверены прямым
чтением; настройки, A, прежние файлы B и дополнительные разделы сохранены.
Образ в репозитории сохраняет стандартную разметку и настройки по умолчанию.
