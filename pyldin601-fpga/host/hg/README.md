# HG для Пълдин-601/601A

`HG.PGM` подключает FAT12-диск хоста через FT2232, используя протокол HG
из uJ11. Он выбирает первый свободный дисковод и синхронизирует дату/время
UniDOS с локальным временем хоста. С обычными ROM- и электронным дисками
получается E:. `HGTIME.PGM` отдельно обновляет время. Оба файла используют
только команды MC6800, расширение HD6303 необязательно.

## Запуск

На Linux нужны Python 3 и `libftdi1-2`, на macOS — Python 3 и Homebrew
`libftdi`. Из директории проекта:

```sh
python3 host/hg/hgfsd.py --directory /home/sash/p601-files
```

Директория должна существовать. Её обычные файлы с именами DOS 8.3 становятся
файлами корня FAT12; регистр существующих имён на хосте сохраняется.
Затем в UniDOS:

```text
B:HG
DIR E:
COPY E:HELLO.TXT A:HELLO.TXT
COPY A:HELLO.TXT E:BACK.TXT
B:HGTIME
```

Программы лежат на B в готовом [`images/sd.img`](../../images/sd.img).
Если подключён другой набор дисков, используй букву из сообщения HG.
После Reset драйвер нужно загрузить снова; аппаратный интерфейс сбрасывается.
Без хоста HG сообщает ошибку и не устанавливает диск. Ожидание ответа имеет
таймаут; отказ хоста не должен оставлять UniDOS в бесконечном ожидании.

## FAT12 и образы

По умолчанию создаётся 32 736 секторов по 512 байт — 16 760 832 байта
(15,984375 МиБ), 8 секторов в кластере, две FAT по 12 секторов и 512 записей
корня. Это предел FAT12 **для кластера 4 КиБ и этой разметки**: 57 служебных
секторов, 4084 полных кластера, 7 оставшихся секторов. Ещё один сектор даст
4085 кластеров и по правилам определения типа файловой системы уже FAT16.

Геометрия SPT=81, heads=2 информационная: HG передаёт логические номера
секторов, без i8272/CHS. Пользовательский проверенный формат 32 400 секторов
выбирается `--blocks 32400`. Ограничение SD-дисков A/B в 1,44 МиБ сохраняется.
Для существующего сырого FAT12-тома и для нового пустого образа:

```sh
python3 host/hg/hgfsd.py --create-image /home/sash/hg.img
python3 host/hg/hgfsd.py --image /home/sash/hg.img
```

`--create-image` не заменяет существующий файл. `--image` поддерживает
подкаталоги через штатный UniDOS; режим `--directory` отображает только
файлы корня. В нём подкаталоги хоста пропускаются, создание подкаталогов
со стороны гостя останавливает экспорт и сохраняет изменения в образе.
`--read-only` запрещает запись гостя. Образ должен содержать BPB FAT12
в секторе 0, без MBR, и 16-битное число секторов в BPB.

Запись сектора подтверждается после `fsync`. В режиме директории файлы
выгружаются после паузы в запросах и проверки обеих FAT/цепочек. Служебные
`.p601-hg.img`, `.p601-hg.json`, `.p601-hg.lock` содержат образ, состояние
и блокировку. Не удаляй их при незавершённых записях: после аварийного
завершения демон восстанавливает файлы из образа перед новым импортом.
При повреждённой FAT он сохраняет образ и прекращает запуск. Не изменяй
обслуживаемые файлы параллельно гостю. Для восстановления сложного тома
используй сохранённый `.p601-hg.img` с `--image`.

## FTDI и JTAG

Подключение такое же, как у uJ11: ADBUS0=TCK, ADBUS1=TDI, ADBUS2=TDO,
ADBUS3=TMS/SELECT. ADBUS7 соединён с JTAGENB (вывод FPGA 120, pull-up на плате).
Демон проверяет низкий уровень ADBUS7 и переключает JTAG-пины в GPIO;
при Ctrl-C/SIGTERM освобождает ADBUS7, возвращая JTAG. Канал B остаётся UART.
После SIGKILL/аварии JTAG можно восстановить:

```sh
python3 host/hg/hgfsd.py --jtag-only
```

Перед запуском Programmer останови HG. Нельзя одновременно занимать
канал A демоном и программатором. Параметры `--serial`, `--index`, `--vid`,
`--pid` позволяют выбрать FTDI; `--clock` задаёт TCK, по умолчанию 100 кГц,
допустимо до 1 МГц. Демон завершает каждый байт USB-чтением, как uJ11,
поэтому скорость диска определяется также USB-задержками.

## Сборка и проверки

```sh
make hg-apps UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
make test-hg UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
make test-hg-hdl UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
```

UniAS создаёт `build/hg/HG.PGM` и `HGTIME.PGM` с заголовком A55A и таблицами
перемещения. Их загружает настоящий PGM-loader UniDOS; установка драйвера
и резидентность соответствуют `native-src/VDISK.601`. Подробности аппаратного
интерфейса и результаты сборки — в [`audit/HG.md`](../../audit/HG.md).
