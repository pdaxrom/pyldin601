# HG для Пълдин-601/601A

`HG.PGM` подключает FAT12-диск хоста через FT2232 и синхронизирует время
UniDOS. С обычными ROM- и электронным дисками первый свободный диск — E:.
Если HG уже установлен второй раз, используй букву из сообщения драйвера.
`HGTIME.PGM` обновляет только время. Обе программы работают на MC6800.

## Нативный сервер

Рабочий демон написан на C11: `hgfsd.c`, `mpsse.c`, `protocol.c`, `volume.c`
и `fat12.c`. Python для его сборки и работы не нужен. Используется libftdi1,
канал A; канал B остаётся UART. На Ubuntu:

```sh
sudo apt install build-essential pkg-config libftdi1-dev
make -C host/hg
build/hg-host/hgfsd --directory /home/sash/p601-files --stats
```

Из корня FPGA-проекта можно выполнить `make hg-host`. На macOS нужны
Command Line Tools, Homebrew `libftdi` и `pkg-config`; та же сборка работает.
Linux следит за папкой через inotify, macOS использует периодическое сканирование.

Директория должна существовать. В UniDOS:

```text
B:HG
DIR E:
COPY E:HELLO.TXT A:HELLO.TXT
COPY A:HELLO.TXT E:BACK.TXT
B:HGTIME
```

После Reset драйвер нужно загрузить снова. Без хоста он сообщает ошибку
и не устанавливает диск. Ожидание ответа имеет таймаут.

## Автоматическое обновление папки

Добавление, изменение, переименование и удаление обычного DOS 8.3-файла
на хосте автоматически меняет образ. Перезапускать сервер не требуется.
На Linux демон ждёт `IN_CLOSE_WRITE` после изменения открытого файла,
проверяет размер/inode/время до и после чтения и выдерживает 0,5 секунды
без новых событий и обращений гостя. Образ заменяется атомарно между
запросами HG. Пока идут обращения к диску, импорт откладывается.

Кластеры и позиции неизменённых файлов сохраняются; замена файла сохраняет
его существующие кластеры, насколько позволяет новый размер. Демон не
переформатирует диск и не упаковывает файлы заново при каждой правке.
Штатный `INT 5C` UniDOS перед новой командой перечитывает FAT и каталог,
если нет открытых файлов. Поэтому очередной `DIR`/`COPY` видит обновление
без переустановки HG. Изменять файл, уже открытый гостем, следует после его
закрытия: протокол передаёт секторы и не сообщает хосту о файловых дескрипторах.

Папка плоская: подкаталоги и скрытые файлы не импортируются. Имена длиннее
8.3 пропускаются с сообщением. Коллизия имён без учёта регистра, symlink,
недостаток места или некорректная FAT откладывают обновление, сохраняя текущий
образ. Переполнение очереди inotify вызывает полное сканирование; дополнительное
сканирование раз в две секунды обнаруживает пропущенные события.

## Запись гостя и восстановление

WRITE подтверждается после `fsync`. Перед первой записью журнал становится
"dirty". После паузы демон проверяет обе FAT и все цепочки, затем объединяет
изменения гостя и хоста относительно последнего согласованного образа.
Независимые изменения сохраняются с обеих сторон. Если обе стороны поменяли
один файл, версия хоста имеет приоритет; изменённое содержимое гостя остаётся
в `.p601-hg-conflicts/` и конфликт записывается в журнал. При конфликте
удаления гостем и изменения хостом сохраняется изменённый файл хоста.

Служебные файлы:

- `.p601-hg.img` — текущий FAT12-том, включая подтверждённые записи гостя;
- `.p601-hg.base` — последний согласованный образ для объединения изменений;
- `.p601-hg.state` — бинарный журнал и соответствие регистра имён;
- `.p601-hg.lock` — блокировка второго демона.

Не удаляй служебные файлы при незавершённых записях. После аварии C-демон
восстанавливает записи и объединяет новые правки папки. Старый формат
`.p601-hg.json` автоматически мигрируется при первом запуске; исходный JSON
сохраняется. После миграции используй C-сервер. Прежняя Python-реализация
оставлена только в `tests/hg_reference.py` как эталон протокола для тестов.

## Установка на sashz-ubuntu

Рабочая директория: `/home/sash/Work/FPGA/pyldin601-hg`.
Файлы диска: `files/`, бинарник: `build/hg-host/hgfsd`.
Управление выполняет пользовательский systemd-сервис:

```sh
mkdir -p files run ~/.config/systemd/user
cp host/hg/p601-hg.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now p601-hg
```

Шаблон рассчитан на `~/Work/FPGA/pyldin601-hg`; для другого пути отредактируй
`WorkingDirectory`, `ExecStart` и `StandardOutput` в unit-файле. Перед первым
запуском останови прежний сервер через SIGTERM, чтобы освободить FTDI.
Сервис запускается при входе пользователя и перезапускается после ошибки.

```sh
systemctl --user stop p601-hg
systemctl --user start p601-hg
systemctl --user restart p601-hg
systemctl --user status p601-hg
# Из рабочей директории те же операции доступны через host/hg/hgctl.
tail -f run/hgfsd.log
```

При ручном запуске в переднем плане остановка — Ctrl-C. SIGINT/SIGTERM
завершают текущий запрос, сохраняют изменения и возвращают JTAGENB в high-Z.

## FAT12 и режим образа

По умолчанию 32 736 секторов по 512 байт: 16 760 832 байта (15,984375 МиБ),
8 секторов/кластер, две FAT по 12 секторов, 512 записей корня. Это максимум
FAT12 для кластера 4 КиБ и этой разметки: 57 служебных секторов, 4084 полных
кластера и 7 оставшихся секторов. Сектор 32737 даёт 4085 кластеров — FAT16.
Проверенная геометрия 32400 секторов выбирается `--blocks 32400`.
SPT=81, heads=2 информационные: HG использует LBA. Ограничение i8272 на
SD-дисках A/B остаётся 1,44 МиБ.

```sh
build/hg-host/hgfsd --create-image /home/sash/hg.img
build/hg-host/hgfsd --image /home/sash/hg.img
```

Создание не заменяет существующий файл. `--image` принимает сырой FAT12-том
с BPB в секторе 0, без MBR; в этом режиме поддерживаются подкаталоги через
UniDOS. `--read-only` запрещает запись гостя; папка всё ещё обновляется с хоста.
Для восстановления без FTDI есть `--directory PATH --sync-only`, для отдельной
проверки отслеживания папки — `--directory PATH --watch-only`.

## FTDI, JTAG и скорость

Подключение как у uJ11: ADBUS0=TCK, ADBUS1=TDI, ADBUS2=TDO,
ADBUS3=TMS/SELECT, ADBUS7=JTAGENB (FPGA 120, pull-up платы).
Демон проверяет низкий ADBUS7 для HG. При остановке возвращает JTAG.
Перед Programmer останови сервис; одновременно занимать канал A нельзя.
После аварийного завершения можно вернуть JTAG отдельно:

```sh
build/hg-host/hgfsd --jtag-only
```

`--serial`, `--index`, `--vid`, `--pid` выбирают FTDI. TCK по умолчанию
1 МГц, максимум 1 МГц. Старые драйверы используют HG v1; HG v2 передаёт
пакеты до 32 байт по кредитам FPGA FIFO. Сохраняются checksum, отдельный
конечный status WRITE, подтверждение завершения и TIME 50/60 Гц.
FIFO переживают паузы CPU/IRQ; DMA, SRAM и её арбитр в HG не участвуют.
`--stats` измеряет время запросов, включая ожидание CPU/FIFO, но не декодирование
и отрисовку изображения между запросами.

## Проверки

```sh
make test-hg-host
make test-hg UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
```

C-тесты исполняют рабочие FAT12, зеркало и dispatcher: HG v1/v2 READ/WRITE/TIME,
контроль фаз/пакетов, checksum, range, read-only, сохранение кластеров, слияние,
конфликт, восстановление и некорректную FAT. Black-box тест запускает настоящий
C-демон и проверяет живые добавление/замену/переименование/удаление, медленное
копирование до закрытия файла, блокировку, переполнение объёма, TERM/restart
и миграцию прежнего кэша. Native UniDOS обеих моделей проверяет обновление
смонтированного диска и повторное COPY без переустановки драйвера.
