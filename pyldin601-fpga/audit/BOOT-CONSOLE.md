# Общая консоль первичного BIOS, 12 октября 2026

Первичный BIOS и загрузчик ROM используют режим 601, 40×24 символа,
один байт на ячейку. Выбор MODEL влияет на имя ROM, заголовок и модель
после handoff; он не меняет загрузочную геометрию. Экран 0400–07BF,
сектор 0800–09FF, настройки/сохранение A00–DFF и заголовок ROM 1000–11FF
сохраняют прежние отдельные области памяти.

Убран переход bootstrap 601А в 40×12 с атрибутами. FPGA передаёт в
видеоконтроллер модель 601 до установки ROM lock, затем выбранную модель.
Штатные видеорежимы системного BIOS и UniDOS сохраняются.

UniAS собрал новый 8192-байтовый bootstrap. Загрузки обеих моделей/ISA,
все 16 настроек частоты, сохранение/EXIT, SDHC/SDSC и 12 сценариев
инициализации/повторной загрузки SD прошли. HDL CPU прошёл handoff,
ROM lock и warm Reset. Два полных classic_system отрисовали реальные
CPU-дампы экрана: 582912 PAL-отсчётов общего текста, 4782 светлых
отсчёта, совпадение за два поля. Отличающиеся названия модели в заголовке
исключены из сравнения. После commit восстановлена модель 601А.

```sh
make test-boot-console test-setup test-sd-init test-handoff UNIAS=/path/to/unias
```

Для установки нужна перепрошивка FPGA: первичный BIOS находится в её EBR.
ROM и LOADER.BIN на SD для этой правки не меняются. FPGA прошита,
Flash Verify ID / Erase,Program,Verify и JTAG Chain — PASS; HG восстановлен.
Пользователь подтвердил одинаковый размер букв при загрузке 601 и 601А:
«да, теперь нормально - размер одинаков». Переход 601А в 80 колонок
отдельно в этом ответе не подтверждён. Новые игровые версии остаются
незакоммиченными.

Diamond: 5168 LUT, 2595 slices, 2085 registers, 22 EBR, 1 PLL; setup/hold
negative slack=0, unconstrained=0, seed 7. Все прежние ограничения SRAM
сохранены. JED SHA-256:
`ee67ff2f85f82dd1460d63f3905d06699d751f7a4f05acdd2186782742cffa95`.
