# Обрезка спрайтов HD6303, 9 октября 2026

`firmware/gfx/GFXCLIP.ASM` пересекает прямоугольник со viewport 320×200.
Знаковые 16-битные координаты позволяют уходить за любой край. Библиотека
корректирует исходный адрес на отрезанные строки/колонки и возвращает
видимый прямоугольник для аппаратного COPY с шагом 320 байт. Она не пишет
MMIO и не копирует пиксели процессором. X сохраняется; D/CCR изменяются.

Входы: `clip_x`, `clip_y` (signed16), `clip_src`, `clip_width` (unsigned16),
`clip_height` (unsigned8). Ширина 1..320, высота 1..200; полный исходный
прямоугольник должен помещаться в первых 64000 байтах страницы. Проверяются
переполнение исходного адреса и невалидные размеры. При C=0 выходы
`clip_source`, `clip_destination`, `clip_draw_width`, `clip_draw_height`
задают видимую часть. При C=1 ширина/высота нулевые. Библиотека проверена
включая координату −32768; вычисления не полагаются на signed16 переполнение.

`CLIPSPR.PGM` двигает три спрайта 32×32 между x=−32..320, y=−32..200.
Они обрезаются, полностью уходят за экран и возвращаются. Для каждой
страницы сохраняется фактический видимый прямоугольник: сначала все старые
прямоугольники восстанавливаются из фона, затем все новые рисуются
прозрачным COPY. Пустой прямоугольник не создаёт команду блиттера.
Страницы 0/1 — кадры, 2 — атлас, 3 — фон; FLIP синхронизирован с VBL.

Нужен HD6303 EXTENSION Y и FPGA graphics v3+. Запуск `B:CLIPSPR` или
`E:CLIPSPR` после `B:HG`; ESC возвращает UniDOS. PGM содержит 1503 байта
кода/данных, 172 relocation, размер файла 1863 байта. Старый SPRITES сохранён.
Все четыре файла CLIPSPR.PGM/ASM, GFXCLIP.ASM, CLIPHOW.TXT добавлены на B
готового SD-образа и атомарно установлены на HG. Пользовательские файлы,
включая LENA.PCX, сохранены; физическая SD не записывалась. FPGA для этого
программного расширения перепрошивать не требуется. 9 октября пользователь подтвердил обрезку, исчезновение/возвращение
спрайтов и ESC на физической плате.

Проверки:

- `test_gfx_clip.c` исполняет настоящий собранный HD6303-код: 249072 случая,
  все 65536 значения X и Y, размеры/источники на границах, случайные
  прямоугольники, X/SP, все четыре края и углы, пустой результат.
- `test_clip_sprites_unidos.c`: оригинальные BIOS/UniDOS 601 и 601A,
  по 400 кадров на запуск, повторные вызовы PGM, полностью вне экрана,
  возвращение, независимая попиксельная модель, фон/атлас/обе истории
  страниц, ESC, guards/error recovery и DIR; сбросов нет.
- `run_clip_sprites_app.py`: реальный VHDL CPU и production GFX/SRAM,
  задержки SRAM-10. 601/8 и 601A/8 МГц, 313 команд и 512000 проверенных
  пикселей на модель; углы/обрезка/фон/ESC, HOLD не используется.
  Полное исчезновение и возвращение покрывает длинный нативный тест.
- NVC ошибочно рассматривает выборку из массива `integer` как unsigned.
  Это воспроизведено отдельным примером `-16 < 320`; в независимом HDL
  эталоне координаты явно приведены `$signed`, проверки пикселей сохранены.

```sh
make test-clip-sprites UNIAS=/Users/sash/Work/FPGA/hd6303-toolchain/unias
python3 tests/run_clip_sprites_app.py --models 0 1 --speeds 3
```

Первый target по умолчанию запускает все модели/частоты; выше перечислены
реально выполненные HDL-комбинации этой версии.
