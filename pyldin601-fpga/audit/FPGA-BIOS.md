# Дополнительный FPGA BIOS и прямой SD

Свободная страница B первого ROM-банка содержит `FPGABIOS`: физически
SRAM 16000–17FFF, логически C000–DFFF, 8 КиБ. Оригинальные BIOS 601/601A
обнаруживают её штатным сканированием ROM и регистрируют INT 17 и INT E0.
Родные BIOS, UniDOS, формат PGM и электронный диск остаются прежними.

`firmware/extension/extension.asm` и SERVICES.ASM собираются существующим
UniAS. Директива `CHECKSUM` формирует штатную сумму всей страницы; сумма
8192 байтов по модулю 256 равна нулю. Скрипт сборки запускает UniAS и
проверяет результат, собственных кодировщиков инструкций здесь нет.
В контейнерах P601.ROM/P601A.ROM дополнительно пересчитывается их CRC32.

```sh
make firmware UNIAS=/path/to/hd6303-toolchain/unias
```

## INT 17

Дисковый код использует только MC6800 и работает с обеими выбранными ISA.
Регистры: A — операция, X — исходный шестибайтовый параметр BIOS:
drive, track, head, sector, bufferHi, bufferLo. Диск 0/1, сектор с единицы,
512 байт; X, SP и исходная ROM-страница сохраняются.

| A | Действие |
|---|---|
| 00/80 | Инициализация: чтение MBR и BPB обоих дисков |
| 01 | Чтение сектора |
| 02 | Запись сектора |
| 03 | Seek/read ID, B возвращает дорожку |
| 04 | Форматирование с проверкой C/H/R/N и заполнением из FDDPARMS |
| FF | Timer/motor tick: возврат без изменения временного состояния |

Результат A: 0 успех, 04 неверный адрес, 10 неверный CRC, 40 отклонённая
запись, 80 отсутствие/неготовность карты или таймаут. Bit 7 double-step
не влияет на SD. Автономных FDC/SD FSM, секторного EBR и DMA SD→SRAM нет.
E6D0 читает постоянный 80h для штатной проверки наличия контроллера.
E6C0/E6D1 не декодируются аппаратно.

MBR-разделы 2/3 выбирают A/B; bit 1 E6A2 меняет их местами при boot B.
Драйвер проверяет тип FAT12, ненулевые start/count, 32-битное переполнение,
пересечение с boot-разделом и друг с другом. BPB проверяется на 512-байтовый
сектор, сигнатуру 55AA или штатную A55A, размер кластера, reserved/FAT/root,
число секторов, spt и heads. CHS преобразуется в относительный LBA,
проверяется против BPB/MBR, затем складывается с началом раздела.
SDSC использует байтовый адрес с проверкой переполнения.

Проверенный загрузочный профиль остаётся до 80×2×18 секторов: ограничения
геометрии в первичном BIOS ещё не расширены для больших SD-дисков.
На HG максимальный FAT12 используется независимо от этого профиля.

CMD17/CMD24 работают через E661–E663; runtime divider=0 даёт SCK 12 МГц.
Фактическая скорость PIO зависит от CPU. CRC16 проверяется при чтении и
формируется при записи. Ответ, token и busy имеют ограниченное ожидание;
запись заканчивается только после полного FFh. CS освобождается при успехе
и ошибке. IRQ разрешаются согласно исходной маске вызывающего кода;
штатные 50-Гц часы и клавиатура продолжают работать.

Состояние дисков занимает BF80–BF9F (32 байта, область BIOS). Временные
переменные используют только прежнюю область FDC ED61–ED7D. Инициализация
временно выделяет сектор 512 байт на стеке и возвращает SP. Keyboard,
console и RS work areas не затрагиваются. Таблицы CRC занимают 512 байт ROM.

## INT E0

A выбирает функцию. X и SP сохраняются; дескрипторы должны лежать в RAM,
доступной при выбранной странице B. A=0 успех, 1 неверные аргументы,
2 ошибка/таймаут оборудования, 3 требуется HD6303.

| A | Вход и действие |
|---|---|
| 0 | Информация: A=1 (версия API), B=0Fh (indexed/HAM8/blitter/AY) |
| 1 | B=0 native, 1 indexed, 7 HAM8; таблицы HAM готовит вызывающий код |
| 2 | B=страница 0..15; FLIP и ожидание VBL |
| 3 | X: cmd,key,srcpage,dstpage,srcBE,dstBE,widthBE,height; FILL=1/COPY=2/keyed COPY=6 |
| 4 | X: signed xBE,yBE,srcBE,widthBE,height,srcpage,dstpage,key; прозрачный спрайт с обрезкой, HD6303 |
| 5 | X: 14 байтов AY R0..R13; R13=FF пропускает запись envelope shape |
| 6 | Выключить три канала AY; штатный beeper остаётся доступен |

Функция 4 возвращает успех без аппаратной команды для невидимого
прямоугольника. Формат страницы — stride 320, максимум 320×200.
Все графические команды ждут BUSY с таймаутом и возвращают ERROR.

## Проверки

`make test-direct-sd` исполняет UniAS ROM через оригинальный banked SWI:
601/601A × MC6800/HD6303 × SDHC/SDSC. По 94 вызова, чтение/запись/формат,
CRC, busy, CHS bounds, boot B, 21 повреждённая MBR/BPB, отсутствие карты,
восстановление, IRQ/CS/ROM/SP и warm reset. Записи вне выбранных секторов
исключены сравнением полного образа; обращения к удалённому FDC запрещены.

`make test-extension-services` проверяет оригинальный INT E0 на обеих
моделях и ISA, fill/keyed COPY, 144 позиции спрайта по четырём краям и
углам, невидимые/extreme координаты, busy/error/timeout и AY frame/silence.
`make test-ay-app` проверяет настоящий PGM, темп от 50 Гц и ESC в UniDOS.
Новая версия требует обновления обоих ROM-файлов на первом разделе SD
до использования прошивки без FDC. 9 октября обе ROM на физической SD
обновлены и проверены прямым чтением; FPGA прошита с FLASH Verify.
MBR, A/B, настройки и 11 таблиц EBR сохранены. Пользователь подтвердил
загрузку, несколько DIR с A/B и полный Reset удержанием 10 секунд,
а также мелодию AY через HG и возврат UniDOS по ESC. Модель и частота
отдельно не указаны; физическая запись файла новым драйвером ещё не проверялась.
