# ROM-службы SD, графики и звука

Новый комплект ROM содержит 64 КиБ страниц и отдельный BIOS 4 КиБ:

| Страница | Физическое размещение | Назначение |
|---|---|---|
| A | 14000–15FFF | SDPARTS, INT E1; разделы SD и запуск UniShell |
| B | 16000–17FFF | FPGABIOS, INT E2/E0, программная PS/2-клавиатура |
| E | 1C000–1DFFF | RAMBANKS INT E5, GAMEBIOS INT E6 — графика/текст/AY |
| F | 1E000–1FFFF | UniShell, INT E3; вся сжатая оболочка UniDOS |
| BIOS | 20000–20FFF | BIOS 601 либо 601A |
| FONT | 21000–217FF | Шрифт |

ROM/RAM-драйверов нет. Запуск системного BIOS заменяет чтение дискеты
вызовом INT E1 A=7; абсолютные входы последующих BIOS-процедур сохранены.
INT E3 страницы F распаковывает всю оболочку UniDOS в RAM с 1000.
В странице A остаётся вызов сервиса и запуск оболочки; её хвост удалён.
[Формат и проверки сжатия](UNISHELL-COMPRESSION.md).
Исходники родного UniDOS собираются UniAS; собственных кодировщиков
инструкций в производственной сборке нет. UniAS CHECKSUM формирует
сумму страниц; контейнер P601BOOT дополнительно защищён CRC32.

Менеджер RAM занимает 240 байт BIOS heap и использует адрес своего
вектора E5 для постоянного состояния. `close_PCB` в UniDOS освобождает
банки завершающейся программы. [API и владение](RAM-MANAGER.md).

```sh
make firmware UNIAS=/path/to/hd6303-toolchain/unias
```

## Клавиатура: приватный IRQ-сервис E7

Состояние драйвера размещается в 64 байтах BIOS heap, указатель — EFCE.
Это приватный слот: приложение не должно вызывать его через SWI.
IRQ-диспетчер 601/601А переключает страницу B, вызывает MC6800-совместимый
обработчик и восстанавливает E6F0/E6F1. Обработчик переводит Set 2,
пишет код в E628 и строб в E62A; далее работает прежний INT09.
Старые INT09/INT10/INT11 и native repeat сохранены.

Таблицы переводов находятся в ROM, а в FPGA — только PS/2-приёмник,
FIFO и регистры совместимости. Для игр предусмотрен прежний эксклюзивный
raw capture: ROM не забирает байты до release. После возврата состояние
модификаторов очищается. [Регистры, ограничения и проверки](KEYBOARD.md).

## INT E2: физическая карта

Индикатор операции использует актуальный `system_scrbase` ($ED20).
Последний символ второй служебной строки расположен по смещению 81
у 601 и 159 у 601А. У 601А физическая ширина строки остаётся 80 байт
и в 40-колоночном цветном, и в 80-колоночном монохромном режиме;
в цветном режиме изменяется только байт символа, его атрибут сохраняется.
Модель читается из bit0 регистра $E6A0. Общая процедура `INDICATOR.ASM`
сохраняет A/B и используется прямым SD-драйвером и исторической страницей
совместимости. По завершении операции, включая ошибку, символ очищается.

`test-raw-sd` проверяет положение R/W во время реальной передачи сектора,
очистку, соседние ячейки и перенесённый адрес экрана для обоих процессоров
и SDHC/SDSC. Для проверки соседних ячеек таймер временно остановлен:
родной обработчик часов обновляет всю служебную строку. Остальные проверки
чтения/записи выполняются со штатными прерываниями.

Исправленные ROM установлены на SD 11 октября 2026. Пользователь подтвердил
на плате в режиме 601А, 80 колонок: индикатор при DIR A:/B: и копировании
расположен в последнем символе справа и очищается после завершения.

| A | Параметр X | Действие |
|---|---|---|
| 0 | Адрес четырёх байтов | Число физических секторов, LE32, из CMD9/CSD |
| 1 | Адрес дескриптора | Чтение сектора |
| 2 | Адрес дескриптора | Запись сектора |

Дескриптор: bufferHi, bufferLo, LBA0, LBA1, LBA2, LBA3. Один сектор 512
байт; буфер должен целиком лежать в доступной RAM, без ROM/I/O/переполнения.
SDHC использует sector addressing, SDSC — byte addressing. X, B, SP и ROM
page сохраняет штатный диспетчер SWI. A возвращает 0 при успехе, 3 защита
записи, 4 диапазон, 5 CRC/данные, 6 ошибка обмена/таймаут.
Проверяются CRC16, ответ CMD24 и полное окончание busy.
INT 17 оставлен только для штатного периодического A=FF (noop); других
дискетных операций больше нет.

## INT E1: разделы

| A | Параметр | Действие |
|---|---|---|
| 0 | — | Инициализация, CMD9, MBR/EBR и проверка BPB |
| 1 | B=индекс, X=24-байтовый буфер | Копия записи; A=2 за концом списка |
| 2 | B=номер раздела | Подключить; B=номер присвоенного диска при успехе |
| 3 | B=номер раздела | Отключить |
| 4 | B=номер диска 0…7 | Отключить |
| 5 | — | Пересканировать с сохранением подключённых томов |
| 6 | B=номер раздела | Форматировать неподключённый FAT12 |
| 7 | — | Выбрать загрузочный том, подключить остальные, запустить UniDOS |

Запись: LE32 start, LE32 count, number, type, active, drive (FF если нет),
BE16 native-header, BE16 total-sectors, LE32 table-LBA, slot, BPB-valid, 0, 0.
Постоянная область heap службы занимает 1536 байт для сектора, 32 записей,
MBR, состояния и visited EBR. REFRESH временно выделяет ещё 768 байт для
снимка отката и освобождает их через штатный heap API при любом исходе.
Дополнительным буквам служба выделяет заголовок и
буферы FAT/каталога по 605 байт. BF80–BF9B — её частные регистры, BF9C–BF9F —
ёмкость SD. SD scratch ED61–ED7B/ED7E–ED7F не затрагивает ED7C/ED7D клавиатуры.
[Политика загрузки, утилиты и проверки](STORAGE.md).

## INT E0: графика и звук

Интерфейс сохранён: A=0 версия/features, 1 видеорежим (B=0 выключает
расширенную графику), 2 FLIP, 3 блиттер, 4 прозрачный спрайт с обрезкой,
5 кадр AY, 6 выключить AY. Номера соответствуют
`firmware/extension/SERVICES.ASM`.
Дескрипторы и ограничения описаны в
[GRAPHICS.md](GRAPHICS.md), [SPRITE-CLIPPING.md](SPRITE-CLIPPING.md) и
[AY.md](AY.md). HAM8 остаётся режимом 7; HAM6 отсутствует.


INT E0 A=0 возвращает API version 1 и features=1Fh; bit 4 сообщает
поддержку музыкального IRQ INT E4 в BIOS 601/601А. Hardware отдельно
идентифицируется по E691=59h. [Регистры таймера и делителя](AY.md).
INT05 остаётся штатным PAL-таймером; EFC8/EFC9 — адрес музыкального
обработчика, high nibble EDF2 — его страница. Диспетчер подтверждает
музыкальный источник и сохраняет оба регистра банков как для IRQ/NMI.
